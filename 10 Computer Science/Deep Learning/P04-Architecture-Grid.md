# P04 架构：网格（Grid）——从 MLP 到 CNN 的结构化建模

## 0. 这节课的路线图
这是架构系列的第一讲：从“多层感知机（MLP）”走向“把结构直接写进模型里”。

课程安排大致是：
1. 为什么要更好的架构、什么叫“更好”
2. 卷积层：把网格结构的归纳偏置写进网络
3. 金字塔与感受野：层叠 CNN 之后到底在获得什么
4. 组件速览：过去十年推动进展的一些模块
5. 神经场（neural fields）与位置编码（positional encoding）的初步引入

## 1. 为什么要“更好的架构”
讲座把“架构”看成一种把假设空间（hypothesis space）提前做限制/塑形的方式：
- MLP 很通用，但对数据结构“没偏好”
- 好架构=把你相信的数据规律（归纳偏置）融进模型，让模型更容易学到“对的那类函数”

一个很关键的观点是：**更好的架构往往意味着更高效地近似你关心的函数类**（这和 P03 的近似理论直接呼应）。

## 2. 先用一个“表示论”的例子：傅里叶基为什么适合图像
讲座在正式讲 CNN 前，用傅里叶基（正弦波）说明“选对表示/结构”的价值：
- 傅里叶基能用一组正弦波来表示图像信号
- 某些结构让压缩/计算更高效（比如 FFT 的直觉）

这里的目的不是让你去背傅里叶，而是让你接受：**结构=效率**。

## 3. 卷积神经网络（CNN）：三件事写进架构
课程把卷积层的核心特性讲得很清楚，可以归纳成三点：

### 3.1 平移等变性（equivariance）
卷积对平移是等变的：
- 输入平移 → 输出也随之平移（而不是不变）
- 这符合很多网格数据（比如图像）里“局部模式在不同位置都可能出现”的直觉

### 3.2 局部连接（local connectivity）
卷积核只看局部邻域：
- 每个位置的输出只依赖一个局部窗口
- 这把“局部性”作为强假设写进模型

### 3.3 参数共享（parameter sharing）
同一个卷积核在整张网格上滑动：
- 大幅减少参数量
- 强化“同一类特征可以在任何位置出现”的归纳偏置

讲座里还有一句很“降维打击”的总结：**卷积层可以看作线性层的受限版本**（少自由度但更贴近数据结构）。

为了复习方便，可以把“卷积/相关”写成一个离散形式（以 1D 为例）：
```text
y[i] = Σ_k w[k] · x[i+k]
```
讲座也提醒：深度学习里常说的“卷积”在实现上通常更接近信号处理里的相关（不一定翻转核），但大家依然习惯叫它 convolution。

平移等变性也可以写成一句话：
```text
Conv(T_Δ x) = T_Δ Conv(x)
```
其中 `T_Δ` 表示把输入平移 `Δ`。

## 4. 多通道卷积、多个滤波器：CNN 是怎么变强的
讲座对多通道的解释是标准但很关键：
- 输入有多个通道（例如 RGB）
- 每个输出通道对应一个滤波器组：对每个输入通道卷积再求和
- 多个滤波器让网络能学到不同的局部模式

这部分你复习时至少要能回答：**“一个卷积核到底在做什么？权重维度如何对应输入输出通道？”**

## 5. 池化、下采样、金字塔：感受野怎么长出来的

### 5.1 池化（pooling）
讲座讨论了常见池化：
- 最大池化（max pooling）
- 平均池化（mean pooling）

池化带来的直接效果是：压缩空间维度、增加某种不变性（更不敏感于小位移/局部扰动）。

### 5.2 下采样（downsampling）
除了“池化再下采样”，也可以直接做下采样；讲座强调这些操作经常组合在一起，用来：
- 控制计算量
- 扩大有效感受野

### 5.3 感受野（receptive field）
堆叠卷积层 + 池化/下采样，会让更深层的特征覆盖更大范围的输入区域。
讲座把这解释成一种**计算量与感受野之间的权衡**：想看更远，就要付出更多计算/更深结构/更强下采样。

## 6. 架构空间很大：从手工设计到“神经架构搜索”
课程提到架构空间非常广阔，既可以手工设计，也有系统化搜索（NAS）的方向。你可以把它当成“把架构当超参数优化”的更极端版本。

## 7. 神经场与位置编码：提前埋一个伏笔
本讲最后引入“神经场”和“位置编码”，并说明后续 Transformer 讲座会展开。

复习时你可以先记一句话：
- 神经场：用网络表示一个连续空间中的场（把位置映射到信号/属性）
- 位置编码：把坐标信息注入模型，使模型能利用“在哪里”的信息
