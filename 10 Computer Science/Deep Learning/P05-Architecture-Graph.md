# P05 架构：图（Graph）——图神经网络（GNN）怎么“尊重结构”

## 0. 为什么要学图网络
这讲延续架构系列，把输入从“规则网格”推广到“任意图结构”：
- 图 = 节点（nodes）+ 边（edges）
- 节点/边都可以有属性（向量/类型）

讲座给了多种动机/例子：道路网络、药物干预与蛋白质关系图、粒子系统（节点是原子/粒子，边表示相互作用）等。

## 1. 图上常见任务（你到底想预测什么）
从学习目标看，GNN 可以回答：
- 节点级问题：节点分类/节点属性预测（node classification）
- 图级问题：整张图分类/回归（graph classification）
- 结构级问题：边/关系预测、在图上做搜索启发式等

## 2. 输入表示：节点属性矩阵 + 邻接矩阵（以及可能的边类型）
讲座把图的输入拆得很具体：
- `X`：节点属性矩阵（每行一个节点的属性向量）
- `A`：邻接矩阵（表示哪些节点相连）
- 真实数据里还会有不同类型的节点/边、边属性等（讲座在药物-蛋白例子里强调了这一点）

## 3. 最关键的约束：置换不变性 / 置换等变性
讲座用一个非常直观的问题指出“直接把 A 和 X 序列化喂给网络”的坑：
- 你给节点编号（索引）的方式是任意的
- 换一种编号，本质上是同一张图，但矩阵表示会变

所以我们希望模型满足对“重编号”的正确对齐：
- **图级输出**要对置换不变（permutation invariance）：怎么重编号都输出同一个答案
- **节点级输出**要对置换等变（permutation equivariance）：输入节点顺序怎么变，输出节点预测也按同样方式变

讲座还把这和 CNN 的平移等变/不变做了类比：**网格上的平移，对应图上的置换。**

## 4. CNN 其实是 GNN（在网格图上的特例）
讲座里有一句很抓人的话：CNN 其实就是 GNN。
直觉是：
- 图像可以看作网格图（每个像素/patch 是节点，边连接邻域）
- 卷积就是在每个节点上做“聚合邻居信息 + 更新自身表示”的局部规则

这句话的意义在于：你可以把“消息传递”当成一个更一般的卷积概念。

## 5. 消息传递（Message Passing）框架：先聚合，再更新
讲座把一般 GNN 的计算写成两步循环：
1. **Message/Aggregate（聚合）**：每个节点从邻居收集信息，并用一个置换不变的聚合函数得到消息 `m_v`
2. **Update（更新）**：用节点当前表示和聚合到的消息更新节点表示

一个常见的抽象写法（只要抓住结构就行）：
```text
m_v = AGG({ h_u : u ∈ N(v) })
h_v' = UPDATE(h_v, m_v)
```
关键约束：`AGG` 必须对邻居集合的顺序不敏感（置换不变）。

讲座也强调了图结构的现实复杂性：
- 每个节点的邻居数量不固定
- 邻域形状不固定
所以你必须用“集合函数”的方式处理邻居，而不是用固定长度的序列假设。

## 6. 多轮消息传递 = 看更远的邻居
当你把上述过程重复 K 次：
- 第 1 轮：只看 1-hop 邻居
- 第 2 轮：信息可以传到 2-hop
- ...
这和 CNN 里“层数更深 → 感受野更大”的逻辑是一致的。
