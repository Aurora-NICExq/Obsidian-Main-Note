# P10 架构：记忆（Memory）——序列建模从“固定窗口”走向“可控记忆”

## 0. 这节课在架构系列里的位置
这是架构系列的最后一个主题：记忆与序列建模。

讲座的路线图非常清晰：
1. 为什么要建模序列/时间/顺序关系
2. 用 CNN 做序列（把时间当成另一个维度做卷积）
3. RNN（循环神经网络）：显式引入隐藏状态作为记忆
4. LSTM：用门控机制解决 RNN 的“遗忘/长期依赖”问题
5. 序列建模与长记忆、自回归（autoregressive）方法

讲座还强调：这一类模型可以视为非常通用的架构框架，甚至讨论到“图灵完备”的表述。

## 1. 序列建模的动机：单帧够用，但很多信息在时间里
讲座用视频/视觉的例子说明：单帧能理解很多，但序列里还包含：
- 运动、因果、变化趋势
- 需要利用过去上下文才能做出更稳的判断

序列不仅是视频：语言、音频、传感器、医学影像随时间变化的体积数据等都属于序列。

## 2. 用 CNN 处理序列：时间卷积 = 固定窗口的局部建模
把时间当成额外维度后：
- 你可以做时间卷积（像 1D/3D CNN 那样）
- 模型可以处理任意长度的序列（只受输入长度约束）

但讲座指出一个核心限制：卷积天然偏“固定窗口”。
当序列变得很长时：
- 很难“记住”很久以前发生的事
- 想看更远就要堆更多层/更大感受野，成本上升

这引出了“需要记忆单元”的动机：超越固定窗口捕捉上下文。

## 3. RNN：把记忆写成隐藏状态（hidden state）
讲座用一个标准形式描述 RNN：
- 每个时间步有输入 `x_t`
- 有隐藏状态 `h_t` 作为“到目前为止的记忆摘要”
- 隐藏状态更新函数在时间上共享（同一套参数反复用）

一种常见写法：
```text
h_t = f(h_{t-1}, x_t)   （时间共享）
y_t = g(h_t)            （时间共享）
```

重要直觉：
- “循环”来自 `h_{t-1} → h_t → h_{t+1}` 这种反馈结构
- 隐藏状态的目标是携带“最相关的历史信息”

## 4. 训练上的现实：截断的时间窗口（Truncated BPTT）
讲座讨论了一个训练层面的事实：虽然理论上时间窗口可以很长甚至无穷，但训练常常会截断：
- 只回传有限长度的梯度
- 把“无限窗口”近似成“有限窗口”

这与计算/内存成本、稳定性等直接相关，也会影响长期依赖的学习效果。

## 5. RNN 的长期依赖难题：遗忘与（隐含的）梯度问题
当时间跨度很长时，RNN 往往会“忘掉”早期信息。
讲座把它作为转向 LSTM 的动机：我们确实需要一种机制，让模型能更明确地控制“记住什么、忘掉什么”。

## 6. LSTM：默认不遗忘，然后学习如何遗忘
讲座对 LSTM 的一句话总结很有辨识度：
> LSTM 的设计更像“默认不遗忘”，然后学习遗忘。

结构上，讲座强调两个状态：
- `h_t`：隐藏状态（输出相关）
- `C_t`：细胞状态/记忆状态（更像“磁带”，讲座类比图灵机）

核心机制是门控（gating）：
- 通过逐元素乘法的掩码，决定哪些信息保留、哪些信息删除
- 让“记忆控制”变成可学习的部分

讲座也提到：这种带门控记忆控制器的结构，带来更强的表达能力，并再次触及“图灵完备”的框架性描述。

## 7. 自回归（Autoregressive）序列模型：用过去预测未来
讲座最后把序列建模的一个经典范式说清楚：自回归。
- 核心思想：在时间 `t` 预测 `t+1`（或下一步）内容
- 预测结果会作为后续输入的一部分（训练时与推理时会有细节差异，但讲座主线是概念）

讲座指出：很多视觉/语言模型会明确训练成自回归模型；Transformer 讲座里的因果注意力也和这一范式直接对应。
