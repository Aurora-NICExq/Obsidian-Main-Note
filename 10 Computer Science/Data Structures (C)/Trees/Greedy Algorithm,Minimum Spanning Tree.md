# 贪婪算法与最小生成树

> [!info] 存根
> 贪婪算法通过反复做出局部最优选择来构造解。**最小生成树（MST）** 用最小的总边权连接带权[[Graph|图]]的所有顶点，通过贪婪算法（如 Kruskal 或 Prim 算法）计算。本笔记为占位符——内容待补充。
