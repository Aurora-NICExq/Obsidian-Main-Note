# Lec01 Introduction：算法与计算模型

## 本讲主线
- 课程目标不是“背算法”，而是训练三件事：定义问题、证明正确、分析效率。
- 研究对象是**任意规模输入**上的一般问题，而不是某个固定小实例。
- 后续所有算法设计，都会围绕 `problem -> algorithm -> correctness -> efficiency` 这条链条展开。

## 核心概念

### 1. Problem
- 问题是“输入到合法输出”的二元关系。
- 对大规模输入，通常不可能枚举所有正确输出，因此要给出一个**可验证的正确性条件**。
- 课程关心的是输入规模可任意增长的问题。

### 2. Algorithm
- 算法是把每个输入映射到一个输出的确定性过程。
- 一个算法“解决”某问题，当且仅当它对每个合法输入都返回正确输出。

### 3. Correctness
- 程序长度固定，但输入规模不固定，因此正确性证明不能靠枚举。
- 递归和循环的本质都要求我们使用**归纳法**证明正确性。
- 生日匹配例子中，证明思路是对“已检查的学生数量 `k`”做归纳。

### 4. Efficiency
- 机器运行时间不适合作为统一标准，因此课程采用**基本操作计数**。
- 输入规模记作 `n`，复杂度研究的是算法随 `n` 增长的趋势。
- 渐进记号：
  - `O(f(n))`：上界
  - `Omega(f(n))`：下界
  - `Theta(f(n))`：紧界
- 一个常见目标是多项式时间；指数时间通常不可接受。

### 5. Word-RAM 模型
- 本课程默认模型是 **Word-RAM**。
- 一个 machine word 有 `w` 位，内存是可寻址的 word 序列。
- 在 `O(1)` 时间内可以做：
  - 常数个 word 的算术运算
  - 逻辑/位运算
  - 按地址读写内存
- 为了能索引全部内存，通常要求 `w >= log n`。

## 数据结构视角
- 数据结构是“存储非定长数据并支持一组操作”的方式。
- 一组操作构成一个**接口**。
- 本课程后续两大接口：
  - `Sequence`：外部顺序，关心第几个元素
  - `Set`：内部顺序，关心 key 的大小关系
- 例子：静态数组支持
  - `build`：`Theta(n)`
  - `get_at(i)`：`Theta(1)`
  - `set_at(i, x)`：`Theta(1)`

## 生日匹配例子
- 朴素做法：对每个学生，与之前见过的所有学生比较生日。
- 若用静态数组存历史记录：
  - 外层循环 `n` 次
  - 第 `k` 次最多比较 `k` 次
- 总复杂度：

```text
O(n) + sum_{k=0}^{n-1} O(k) = O(n^2)
```

- 这说明：**同一个问题，换数据结构就可能换复杂度**。

## 这一讲真正要记住的东西
- 算法学习不是只会写代码，而是要同时会：
  - 描述问题
  - 写出算法
  - 用归纳法证明
  - 用渐进分析评价好坏
- Word-RAM 是后续“随机访问数组为何能做到 `O(1)`”的基础。
- 数据结构的选择会直接决定算法效率。
