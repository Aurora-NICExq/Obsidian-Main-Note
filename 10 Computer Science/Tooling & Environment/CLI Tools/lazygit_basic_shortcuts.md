# Lazygit 基本快捷键操作说明

Lazygit 是一个终端里的 Git 图形界面工具。进入 lazygit 后，可以通过键盘完成查看状态、暂存、提交、推送、拉取、切换分支等常见操作。

## 导航（Navigation）

- `?` ：查看当前面板可用快捷键
- `Tab` / `Shift+Tab` ：切换到下一个 / 上一个面板
- `1` ~ `5` ：快速跳转到指定面板
- `j` / `k` ：向下 / 向上移动选择
- `h` / `l` ：进入左侧 / 右侧层级或面板
- `Enter` ：进入当前选中项的详情视图
- `Esc` ：返回上一级或关闭弹窗
- `/` ：在当前列表中过滤或搜索
- `q` ：退出当前视图或退出 lazygit

## 文件操作（Files）

- `Space` ：暂存 / 取消暂存当前文件
- `a` ：暂存 / 取消暂存所有文件
- `Enter` ：查看当前文件的修改详情
- `d` ：丢弃当前文件的修改
- `e` ：用外部编辑器打开当前文件
- `s` ：将当前修改保存到 stash
- `S` ：打开 stash 相关操作菜单

## 代码块与行级暂存（Hunks / Lines）

- `Enter` ：进入文件的 hunk 视图
- `Space` ：暂存 / 取消暂存当前 hunk 或当前行
- `v` ：进入可视选择模式，用于选择多行
- `a` ：暂存 / 取消暂存整个 hunk
- `E` ：在编辑器中编辑当前 hunk

## 常见 Git 操作

- `c` ：提交已经暂存的更改
- `A` ：将已暂存内容追加到上一次提交
- `p` ：拉取远程更新
- `P` ：推送本地提交到远程仓库
- `f` ：抓取远程分支和提交信息
- `R` ：刷新当前仓库状态
- `z` ：撤销最近一次 lazygit 操作
- `Z` ：重做最近一次撤销的操作

## 分支操作（Branches）

- `Space` ：切换到当前选中的分支
- `n` ：新建分支
- `d` ：删除当前选中的分支
- `M` ：将选中分支合并到当前分支
- `r` ：将当前分支 rebase 到选中分支
- `u` ：设置当前分支的 upstream
- `p` ：拉取当前分支对应的远程更新
- `P` ：推送当前分支到远程仓库

## 提交记录操作（Commits）

- `Enter` ：查看当前提交详情
- `r` ：修改提交信息
- `d` ：删除当前提交
- `s` ：将当前提交 squash 到前一个提交
- `f` ：将当前提交 fixup 到前一个提交
- `i` ：开始交互式 rebase
- `Shift+C` ：标记当前提交用于 cherry-pick
- `Shift+V` ：粘贴已标记提交，即执行 cherry-pick

## Stash 操作

- `s` ：保存当前修改到 stash
- `S` ：打开 stash 选项菜单
- `Space` ：应用选中的 stash
- `d` ：删除选中的 stash

## 使用建议

- 不确定当前面板能做什么时，先按 `?`。
- 新手最常用流程是：`Space` 暂存文件 → `c` 提交 → `P` 推送。
- 拉取远程更新通常使用 `p`，推送本地提交通常使用 `P`。
- 删除、丢弃、rebase 等操作前，注意确认当前分支和选中对象。
