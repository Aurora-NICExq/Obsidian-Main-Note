# ⚡ Yazi 快捷键速查表

> 一款快速、 blazing-fast 的终端文件管理器。以下为**默认**按键绑定，所有按键均可通过 `keymap.toml` 重新映射。
> 在 yazi 中随时按 **`~`** 或 **`F1`** 可打开内置交互式帮助。

---

## 🧭 基础导航与移动

| 按键 | 功能说明 |
| :--- | :--- |
| `k` / `↑` | 光标上移 |
| `j` / `↓` | 光标下移 |
| `h` / `←` | 返回上级目录（向外移动） |
| `l` / `→` / `Enter` | 进入目录 / 打开文件 |
| `g` `g` | 跳转到列表顶部 |
| `G` | 跳转到列表底部 |
| `Ctrl+u` / `Ctrl+d` | 向上 / 向下滚动半页 |
| `Ctrl+b` / `Ctrl+f` | 向上 / 向下滚动一页 |
| `H` / `L` | 在目录历史中**后退** / **前进** |
| `K` / `J` | 向上 / 向下滚动**预览面板** |
| `q` | 退出 yazi |
| `Esc` | 取消当前模式（退出可视模式、清除筛选/搜索、取消选择） |

## 📂 文件与目录操作

| 按键 | 功能说明 |
| :--- | :--- |
| `a` | 创建文件，若名称以 `/` 结尾则创建**目录** |
| `r` | 重命名选中的文件/目录 |
| `d` | 将选中的文件移动到**回收站** |
| `D` | **永久删除**选中的文件（不经过回收站） |
| `y` | **复制**（yank）选中的文件到剪贴板 |
| `x` | **剪切**选中的文件到剪贴板 |
| `p` | 将复制/剪切的文件粘贴到当前目录 |
| `P` | 粘贴并**覆盖**已有文件 |
| `o` | 使用默认程序打开选中的文件 |
| `O` | **交互式**打开（选择使用哪个程序） |
| `-` / `_` | 从已复制的文件创建**绝对** / **相对**符号链接 |

**选择辅助：**

| 按键 | 功能说明 |
| :--- | :--- |
| `Space` | 切换当前项目的选中状态，然后向下移动 |
| `v` | 进入**可视模式** — 移动光标时拖选范围内的文件 |
| `V` | 可视模式，但**取消选中**所覆盖的范围 |
| `Ctrl+a` | 选中当前目录中的所有文件 |
| `Ctrl+r` | 反转当前选择 |
| `c` `c` | 将文件的**完整路径**复制到系统剪贴板 |
| `c` `f` | 只将**文件名**复制到系统剪贴板 |

> 💡 **可视模式（`v`）** 是选中连续文件块的最快方式：按 `v`，移动光标，经过的每个文件都会被选中。

## 🔍 搜索与跳转

| 按键 | 功能说明 |
| :--- | :--- |
| `/` | 在当前目录中**向前查找**（实时输入即跳转） |
| `?` | 在当前目录中向后查找 |
| `n` / `N` | 跳转到下一个 / 上一个查找结果 |
| `f` | **筛选**当前视图 — 隐藏所有不匹配的项目 |
| `s` | 按文件名**递归搜索**（基于 `fd`） |
| `S` | 按文件内容**递归搜索**（基于 `ripgrep`） |
| `Ctrl+s` | 取消正在运行的搜索并保留已有结果 |
| `z` | 通过 **zoxide** 跳转到已知目录（基于使用频率的 `cd`） |
| `Z` | 通过 **`fzf`** 模糊跳转到任意文件/文件夹 |
| `g` `Space` | 交互式 `cd` — 输入路径直接跳转 |

> 💡 **查找（`/`）** 与 **筛选（`f`）** 的区别：*查找*将光标移动到匹配项但不隐藏任何内容；*筛选*则从视图中完全移除不匹配的项目。

## 👁️ 视图与排序

| 按键 | 功能说明 |
| :--- | :--- |
| `.` | 切换**隐藏文件**（点文件）的显示 |
| `g` `h` | 跳转到**家**目录（`~`） |
| `g` `c` | 跳转到配置目录（`~/.config`） |
| `g` `d` | 跳转到 `~/Downloads` |

**排序** — 先按 `,` 前缀，再按以下键（大写 = 降序）：

| 按键 | 功能说明 |
| :--- | :--- |
| `,` `a` / `,` `A` | **按字母**排序（升序 / 降序） |
| `,` `n` / `,` `N` | **自然排序**（例如 `2` 排在 `10` 前面） |
| `,` `s` / `,` `S` | 按**大小**排序 |
| `,` `m` / `,` `M` | 按**修改时间**排序 |
| `,` `c` / `,` `C` | 按**创建时间**排序 |
| `,` `e` / `,` `E` | 按文件**扩展名**排序 |

| 按键 | 功能说明 |
| :--- | :--- |
| `t` | 在当前目录打开**新标签页** |
| `1` … `9` | 直接切换到第 1–9 个标签页 |
| `[` / `]` | 切换到上一个 / 下一个标签页 |
| `{` / `}` | 将当前标签页向左 / 向右移动一个位置 |

## ⚙️ 任务管理与 Shell 命令

| 按键 | 功能说明 |
| :--- | :--- |
| `w` | 打开**任务管理器**（查看复制/移动/删除进度） |
| `;` | 运行 **shell 命令**（非阻塞，后台运行） |
| `:` | 运行**阻塞式** shell 命令（等待执行完毕） |
| `Ctrl+z` | 将 yazi 挂起到后台（`fg` 恢复） |

> 💡 在 shell 命令中，`"$@"` 展开为所有**选中**的文件，`"$0"` 为**光标停留**的文件 — 例如：`;` 然后输入 `mv "$@" ~/archive/`。

## 🚀 额外：自定义 `keymap.toml`

配置文件位于 **`~/.config/yazi/keymap.toml`**（Windows 上为 `%AppData%\yazi\config\`）。以下是一些自定义技巧：

1. **覆盖而非替换。** Yazi 会将你的 `keymap.toml` **合并到**默认配置之上，因此你只需定义想要更改的按键。每个绑定是一个包含 `on`（按键）、`run`（命令）和可选的 `desc`（显示在 `~` 帮助菜单中 — 建议始终添加）的表。

   ```toml
   [[mgr.prepend_keymap]]
   on   = "<C-n>"
   run  = 'shell -- nautilus "$PWD"'   # 在当前文件夹中打开 GUI 文件管理器
   desc = "在 Nautilus 中打开"
   ```

2. **链式命令与多键组合。** `run` 可以接受一个数组来依次触发多个操作，`on` 可以接受多个键来创建类似 `g` 前缀的组合键：

   ```toml
   [[mgr.prepend_keymap]]
   on  = [ "g", "p" ]
   run = "cd ~/Projects"             # 按 g 然后 p 跳转到 ~/Projects
   desc = "跳转到 ~/Projects"
   ```

3. **了解优先级。** 使用 **`prepend_keymap`** 让你的按键覆盖默认设置，使用 **`append_keymap`** 添加仅在无其他匹配时触发的后备绑定。按键绑定按层级作用域划分 — `[mgr]`、`[input]`、`[tasks]`、`[help]` — 因此同一按键在不同上下文中可以执行不同操作。编辑后重新启动 yazi 即可加载。
