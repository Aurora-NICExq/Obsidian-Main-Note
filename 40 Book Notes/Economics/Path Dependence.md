# Path Dependence

> [!summary] 核心结论
> 路径依赖指：小事件与历史环境可把系统送上特定轨道，一旦确立就难退出。North 把 Arthur/David 的技术故事推广到制度：制度矩阵的收益递增，加上不完美市场与主观模型，使经济可长期锁定在非最优路径。

> 关键词：收益递增、lock-in、多重均衡、主观模型、历史重要

---

## 1. 技术类比（Arthur）

自我强化机制：高固定成本、学习效应、协调效应、适应性预期。

后果性质：多重均衡、可能无效率、lock-in、path dependence。

## 2. North 的制度版

塑造制度变迁路径的两股力量：

1. **Increasing returns** — 制度创立成本、组织学习、协调与互补投资、非正式约束对正式规则的延伸、适应性预期  
2. **Imperfect markets + transaction costs** — 反馈残缺；意识形态与历史形成的心智模型持续偏置选择

仅有收益递增但市场近似竞争、模型可纠正时，长期仍可「有效」；两者叠加才解释持续分化与劣绩效。

## 3. 稳定含义

- 正式规则可变，文化/非正式约束粘性强 → 增量演化、难跳跃。
- 「History matters」：当下与未来的选择集由制度连续性接到过去。
