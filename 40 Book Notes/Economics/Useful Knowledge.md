# Useful Knowledge

> [!summary] 核心结论
> Mokyr 用语：对自然现象的、可支撑物质生产技术的知识。核心二分是 **Q（命题 / propositional）** 与 **λ（处方 / prescriptive techniques）**；Q 为 λ 提供认识基础。现代增长史很大程度上是有用知识变宽、变紧、变便宜可及的历史。

> 关键词：Q、λ、认识基础、接入成本、紧度

---

## 1. 边界

- 包含科学，但远宽于科学：工匠直觉、材料性质、海流、工程定量关系等。
- 排除（大体）纯社会知识；技术若依赖行为规律则落在灰色区。
