# Gifts of Athena — Useful Knowledge

> [!summary] 核心结论
> Ch1：有用知识 = 关于自然规律与现象、可转化为物质操控的知识。拆成 **Q（propositional，episteme）** 与 **λ（prescriptive techniques，techne）**；Q 是技术的认识基础（epistemic base）。社会知识是头脑与外存的并集；关键参数是**紧度（tightness）**与**接入成本（access costs）**。

> 关键词：Q / λ、认识基础、紧度、接入成本、默会知识

---

## 1. 定义边界

- 有用知识（Kuznets 用语）：自然现象——材料、能量、生物等；大体排除纯社会事实（价格、法律人格等有灰色区）。
- 「我们更富」首先因为集体知道得更多，不一定更聪明。

## 2. Q vs λ

| | Q（命题） | λ（处方 / techniques） |
|--|----------|------------------------|
| 问题 | 是什么 / 何规律 | 如何做 |
| 内容 | 观察、分类、定律、工程经验关系、民俗规律 | 可执行指令、例程、菜谱 |
| 存储 | 心智 + 外存；他者心智也是存储 | 心智、手册、**人工物本身**（部分） |
| 增量 | discovery | invention / 新 technique |

- 文本亦用 A-knowledge / X 指处方集；笔记统一用 **λ**（与通行二手表述一致）。
- Q→λ 映射像基因型→表型：有基不保证被映射；无基则许多技术根本不可得。

## 3. 紧度与接入

- **紧度**：置信 + 共识。太松则难支撑大规模 R&D。
- **接入成本**：IT、信任、Q 规模（越大越需分工）、谁控制外存。成本高 → 难累积、易遗失、重复发明。
- 默会成分随人死而亡，除非传给下一代。

## 4. 历史含义

- 1800 前多数技术认识基窄：能用但难持续改进 → 易「间断后平台」。
- 激励与文化决定是否映射；但不知的东西无法被需求「变」出来。

---

> [!important] 一句话总结
> 技术是写在自然之上的指令集；指令能写多深，取决于社会 Q 有多宽、多紧、多易取。
