# Secular Stagnation

> [!summary] 核心结论
> **长期停滞**（secular stagnation）指持久的低增长体制。Hansen（1938）提出；2008 后 Summers 侧重需求不足与负自然利率，Gordon 侧重「重大发明红利耗尽」。Aghion 等调和 Mokyr 乐观与 Gordon 悲观：科学与创新潜力仍在，但超级明星企业与不当竞争政策可使 IT/AI 波在长期抑制总量创新。

> 关键词：低垂果实、僵尸企业、missing growth、超级明星、动态竞争政策

---

## 1. 争论地图

| 立场 | 机制 |
|------|------|
| Summers | 投资需求弱，需极低/负利率达充分就业 |
| Gordon | 供给：蒸汽/电力/内燃等「好果子」已摘完 |
| Mokyr / 熊彼特派 | IT 改进想法生产；全球化放大创新收益与不创新惩罚 |
| Aghion 本书 | 最重视超级明星劝退其他创新者 + 制度阻力 |

## 2. 本书筛选过的假说

- 研究变难（更多研究者才能维持原增长率）——有部门证据，但非唯一故事。
- **Missing growth**：创造性破坏导致官方物价/产出低估部分真实增长；校正后放缓仍在。
- 信贷宽松与僵尸企业阻碍再配置。
- **主线**：数字超级明星扩大产品线控制 → 非明星气馁 → 增速下滑；需面向创新的反垄断。
