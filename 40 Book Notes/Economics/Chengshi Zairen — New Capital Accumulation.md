# Chengshi Zairen — New Capital Accumulation

> [!summary] 核心结论
> 第十–十一章回答「中国会得日本病吗」：供给侧靠**新资本积累**（数字资本、新能源资本、人力资本）打破低人均资本与低 MPK 并存的悖论；需求侧靠**唤醒乘数**——提高居民消费倾向与矫正财政结构，使既定投资撬动更大 GDP。标题落点：**成事在人**——人口约束下仍取决于资本形态与财政金融选择。

> 关键词：索洛之谜、数字资本、新能源、人力资本、乘数、投资财政

---

## 1. 索洛之谜与为何需要「新」资本（Ch10）

- 索洛：电脑革命处处可见，生产率统计不见——TFP 余值未升。
- 解释线索：GDP 漏计消费端「快感」/消费者剩余；生产端则长期低估**无形资本**；发明要进入生产函数需配套电厂、组织与大量投资，耗时长久。
- 完整资本图景：物质资本 + **数字资本** + **新能源资本** + **人力资本**。

## 2. 三类新积累

| 类型 | 逻辑 |
|------|------|
| 数字资本 | α 型：AI 等通用技术；非竞争性、近零边际成本、对人脑替代；无形资本（数据/算法/知识） |
| 新能源资本 | 算力耗电 → 需可持续电力；化石「历史太阳能」转向当代可再生，类比煤与蒸汽机配对 |
| 人力资本 | 中国退出劳动力目前偏低温；总人力资本仍升，但若政策不调，书中预警最迟约 2029 年达峰 |

目标：找到高 MPK 的投资方向，避免在传统产能上重复日本式资本过剩。

## 3. 唤醒乘数效应（Ch11）

- 企业投资创造居民收入；居民消费决定循环轮次 → 乘数 = \(1/(1-c)\) 逻辑。
- 消费率过低 → 投资率被动过高 → β 被抬高 → MPK 更低（需求侧恶化供给侧）。
- 财政：中央地方事权错配、地方化「投资财政」；债务累积同时福利性消费支持不足。
- 对策方向（书中）：提高居民部门可支配收入与消费倾向；财政支出更多对准高消费倾向群体与人力资本，而非仅堆低效基建或错配年龄结构的补贴。

## 4. 与通论闭合

- 人少了仍可靠信用支持新形态资本深化（α）与人力资本（阻 β 塌方）。
- 人多时曾靠信用兑现红利；人少时更要靠同一链条换挡——故「通论」两端对称，详见 [[Population and Capital]]、[[Chengshi Zairen]]。

> [!important] 一句话总结
> 新资本换生产函数，乘数换循环次数——双管齐下才叫成事在人。
