# Postwar Japan — 1940 System

> [!summary] 核心结论
> 「1940 年体制」= 改革派官僚为打赢战争打造的**国家总动员经济制度**；战败后经济官僚几乎毫发无损，目的从「军需」换成「增产」，成为复兴与高速增长的操作系统。当它不再匹配技术与国际环境时，80–90 年代泡沫是其**垂死挣扎**，泡沫清算与体制消亡同步。

> 关键词：改革派官僚、间接金融、窗口限制、产业报国会、农地/粮管

---

## 1. 体制如何成形（序章）

- **改革派官僚**（岸信介–椎名「统制派」等）：企业为公、反「不劳而获」；岸被小林一三骂「赤色分子」——日本式统制/准社会主义取向。
- **金融**：压股东、立银行中心；1942《日本银行法》明文服务国家目标。
- **财政**：源泉征收、法人税独立、中央集中税收再下拨。
- **农村**：1942《粮食管理法》等削弱地主；双重米价；为兵源与稳定。
- **企业谱系**：九大电力、丰田/日产许可制赶美资、东芝/日立/松下军需扩张、日铁国策公司；道尔：战后大企业仅索尼、本田近乎纯战后出生。
- **社会组织**：统制会 → 行业协会/经团联前身；一县一报；企业内「产业报国会」→ 战后企业别工会。

## 2. 为何战后「续命」（Ch1）

### 2.1 占领军看不清经济实权

- 军需省秒变回商工省（后通产省）；大藏省挡 B 元、保住货币发行权。
- 整肃重军部/内务；**经济官僚与银行体系几乎未动**——占领逻辑按美国财阀想象拆三井三菱，不懂主银行控制。
- 农地改革：农政官僚草案借 GHQ 加压完成，实为**战时改革的完成态**。

### 2.2 日本式管理的战时起源

- 分红上限 + 资金统制 → 直接金融萎缩 → 内部晋升社长、银行发言权上升。
- 企业别工会继承产业报国逻辑：劳资命运共同体，利于增长期「企业战士」。

### 2.3 倾斜生产与配给金融

- 煤钢优先、价格差额补助、复金贷款 → 产能急复 + 通胀。
- **窗口限制**：日银经对民间银行的再贷款权，统制贷款分配；金融锁国 + 抑制利率。
- 野口：若纯靠市场价格，资本会涌向轻工/商业；**重化工业需要这套非市场分配**。

### 2.4 史观判决

- 通常：民主化带来复兴。
- 野口：**复兴 = 1940 体制首战告捷**；断裂在 1940 而非 1945。

## 3. 与泡沫同亡（Ch5 论点）

- 泡沫崩溃后不良债权、住专、山一、长银、大藏省丑闻：金融统制权威崩塌。
- 「泡沫经济是 1940 年体制的垂死挣扎」：体制已不适配，却用资产膨胀延命；清算期 = 体制名实俱亡的过程。
