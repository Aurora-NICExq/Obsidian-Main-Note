# 1940 System

> [!summary] 核心结论
> 野口悠纪雄用语：**约 1940 年前后成形的战时经济总动员体制**，战后几乎原样继承。特征是国家导向资源配置、银行中心间接金融、企业内部劳资共同体、官僚行政指导。它解释了复兴与高速增长，也解释了泡沫与长期停滞。

> 关键词：总动员、间接金融、窗口限制、企业别工会、统制

---

## 1. 构成要件

| 领域 | 战时设计 → 战后形态 |
|------|---------------------|
| 产业 | 统制/许可/国策公司 → 通产行政指导、行业协会 |
| 金融 | 排股东、银行供资、日银为国家目标服务 → 主银行 + 窗口限制 |
| 财政 | 源泉征收、法人税、中央集中再分配 | 
| 劳动 | 产业报国会 → 企业别工会、终身雇用/年功气质 |
| 农业 | 粮管、削弱地主 → 双重米价、减反、保护农户 |
| 信息 | 一县一报等 → 全国纸媒体结构 |

## 2. 史观用法

- **断裂在 1940，不在 1945**：占领改革拆了军部/财阀表象，留下经济操作系统。
- **合拍期**：重化工业 + 追赶型增长（见 [[Postwar Japan — High Growth Mechanism]]）。
- **错配期**：IT/水平分工/金融市场开放；泡沫 = 垂死挣扎（见 [[Postwar Japan — Bubble Collapse]]）。
- **政策回声**：用国家干预、补贴、超宽松保护旧业态 —— [[Lost Three Decades — Export Model and Abenomics]]。

## 3. 与通常「日本式经营」话语

「日本第一」常把共同体企业、长远经营说成文化优点；野口把它**历史化**为战时制度遗产，而非永恒民族性。
