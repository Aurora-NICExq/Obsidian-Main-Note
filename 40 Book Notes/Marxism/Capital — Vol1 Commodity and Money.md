# Capital — Vol1 Commodity and Money

> [!summary] 核心结论
> 资本主义财富表现为庞大的商品堆积；商品是使用价值与价值的统一，其中价值实体是抽象人类劳动，价值量由社会必要劳动时间决定。价值形式从简单到一般再到货币，使私人劳动的社会性质采取物与物关系的外观——这就是[[Commodity Fetishism|商品拜物教]]。货币是一般等价物的完成形态，其职能服务于商品流通，并为下一篇「货币转化为资本」准备条件。

> 关键词：使用价值 / use-value、价值 / value、抽象劳动 / abstract labor、价值形式 / value-form、货币 / money、拜物教 / fetishism

---

## 1. 商品的两个因素与劳动二重性

- **使用价值**：物的有用性；质上不同；是交换价值的物质承担者。
- **交换价值**：一种使用价值同另一种使用价值相交换的量的关系或比例；其共同内容是价值。
- **价值实体**：无差别的人类劳动的单纯凝结（抽象劳动）；**价值量**：社会必要劳动时间。
- **劳动二重性**（理解政治经济学的枢纽）：
  - 具体有用劳动 → 使用价值；
  - 抽象人类劳动 → 价值。
- 私人劳动必须通过交换才证实为社会总劳动的一部分。

## 2. 价值形式或交换价值

发展序列（范畴逻辑，也对应历史轮廓）：

| 阶段 | 要点 |
|------|------|
| A. 简单/偶然 | 相对价值形式 ↔ 等价形式两极 |
| B. 总和/扩大 | 一种商品对无数商品；缺点：表现不统一 |
| C. 一般 | 一切商品共同表现在一种商品上 |
| D. 货币 | 一般等价物社会地固定在金银上 |

等价形式的特征（文本强调）：使用价值成为价值的表现形式；具体劳动成为抽象劳动的表现形式；私人劳动取得社会劳动的形式。

## 3. 交换过程与货币

- 交换使商品占有者彼此当作私有者对待；货币解决「直接产品交换」的困难。
- 货币职能（第一篇后续章）：
  1. **价值尺度**（观念的金）→ 价格；
  2. **流通手段** `W—G—W`；
  3. **贮藏手段**；
  4. **支付手段**；
  5. **世界货币**。
- 价格可以偏离价值；货币量规律与支付链条等为危机分析埋下伏笔（详论多在后卷）。

## 4. 商品拜物教（要点）

> 商品形式把人们本身劳动的社会性质反映成劳动产品本身的物的性质……把生产者同总劳动的社会关系反映成……物与物之间的社会关系。

- 神秘性来自**商品形式本身**，不是来自使用价值或价值规定的「生理学内容」。
- 对照：鲁滨逊、中世纪人身依附、家长制家庭、自由人联合体——社会关系愈直接，拜物教愈淡出。
- 资产阶级经济学范畴是对商品生产有社会效力的思维形式；科学发现劳动是价值实体，并不自动消除物的外观。
- 详见[[Commodity Fetishism]]。

## 5. 通向第二篇

- 简单流通终点是消费；资本总公式要求终点的货币大于起点的货币。
- 若不引入能创造价值的特殊商品——[[Labor Power|劳动力]]，流通领域内的等价交换无法说明增殖。
