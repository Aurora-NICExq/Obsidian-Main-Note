# Capital

> [!summary] 核心结论
> 《资本论》三卷把资本主义当作历史的生产方式：从商品—货币—劳动力入手揭示剩余价值如何在生产中产生（第一卷），再考察资本如何在流通中变换形态并实现社会再生产（第二卷），最后说明剩余价值怎样在竞争中转化为利润、利息、地租等具体形式（第三卷）。中心链是：价值规律 → 劳动力商品 → 剩余劳动 → 积累与有机构成提高 → 利润率趋向下降与收入范畴的神秘化。

> 关键词：价值 / value、劳动力 / labor power、剩余价值 / surplus value、循环与周转 / circuit & turnover、生产价格 / production price、平均利润 / average profit

## 1. 定位与版本

- 作者：卡尔·马克思；第二、三卷由恩格斯据手稿编辑出版。
- 结构：第一册《资本的生产过程》；第二册《资本的流通过程》；第三册《资本主义生产的总过程》。
- 本库笔记依据中文 ME 编译本（马恩全集中文第 2 版脉络 / 历史考证版校订传统）的文本提取；具体页码不钉死于单一纸本。
- 写作史要点（综述）：1857–58 草稿 → 《政治经济学批判》（1859）→ 1861–63 / 1863–65 手稿 → 第一卷 1867；第二卷 1885、第三卷 1894。

## 2. 全书一条链

![[d2-capital-01.svg]]

1. **商品二重性与劳动二重性** → 价值实体是抽象人类劳动；价值量由社会必要劳动时间决定。
2. **价值形式发展** → 一般等价物凝固为货币；货币完成尺度、流通、贮藏、支付、世界货币等职能。
3. **货币转化为资本** → 总公式 `G—W—G′`；矛盾在流通中买等价、卖等价却要增殖 → 必须有特殊商品：**劳动力**。
4. **剩余价值** → 必要劳动 / 剩余劳动；绝对（延长工作日）与相对（缩短必要劳动）；不变资本 `c` / 可变资本 `v`；`m′ = m/v`。
5. **工资** → 劳动力价值/价格的转化形式，掩盖无酬劳动。
6. **积累** → 剩余价值资本化；资本主义关系在扩大规模上再生产；一般规律与产业后备军；**原始积累**是前史（分离）。
7. **流通（第二卷）** → 货币资本 / 生产资本 / 商品资本循环；流通时间与费用；固定/流动资本与周转；社会总资本简单/扩大再生产图式。
8. **总过程（第三卷）** → 成本价格 `k`、利润 `p`、利润率 `p′`；竞争形成平均利润与生产价格；利润率趋向下降；商业资本、生息资本、地租；收入三位一体公式的拜物教完成形态。

## 4. 建议阅读顺序

1. 商品—货币—拜物教 → 劳动力 → 绝对/相对剩余价值（打牢范畴）。
2. 工资、简单再生产、积累一般规律、原始积累（把「起点」历史化）。
3. 循环三公式与周转（理解「实现」与时间）。
4. 两部类再生产（宏观平衡条件）。
5. 成本价格→利润→平均利润/生产价格 → 利润率趋向下降 → 利息与地租（表面形式）。

## 5. 方法提醒

- 从**抽象到具体**：第一卷抽掉竞争与分配的具体形式；第三卷再「一步一步接近」社会表面。
- **c/v**（价值增殖）≠ **固定/流动**（周转）：混同是古典政治经济学的常见错误。
- 短引只保留公式与不可替换术语；细节论证回原书相应篇。

---

> [!important] 一句话总结
> 《资本论》证明：资本不是物，而是以劳动力商品为前提的社会关系；剩余价值在生产中产生，在流通中实现，在竞争中再分配为利润、利息与地租。
