# What Is to Be Done — Professional Revolutionaries

> [!summary] 核心结论
> 「手工业方式」不只是缺经验：它把组织规模压到「群众目前能胜任」的水平，与经济主义政治缩水同源。首要实际任务是建立能使政治斗争有力量、稳定性和继承性的**革命家组织**；工人组织与革命家组织必须区分，不能混为一谈。

> 关键词：手工业方式、职业革命家、工人组织 vs 革命家组织、密谋与民主制、集中

---

## 1. 什么是手工业方式

- 症候：罢工缺少有力影响、传单书刊不足、鼓动员缺、经费缺；运动增长超过组织；青年鼓动员数月即被捕，组织无继承性。
- 除缺乏修养外，更指：整个革命工作规模被缩小，迁就「能够胜任的」斗争与「能够胜任的」组织。
- 两极都屈服于它：机会主义者只要渐进工联组织；「革命主义者」以为总罢工或激发性恐怖即可，不必建坚强革命家组织。

## 2. 工人的组织 ≠ 革命家的组织

| | 工人组织（如工会） | 革命家组织 |
|--|-------------------|------------|
| 性质 | 职业的 | 政治领导核心 |
| 广度 | 尽量广泛 | 人数少、紧密、经考验 |
| 秘密性 | 尽量少（专制俄国条件下） | 严格秘密；其余条件服从秘密性 |
| 成员 | 不应要求人人是社会民主党人 | 职业革命家 + 多样化外围组织 |

- 经济派把「革命家组织」听成「罢工储金会」——组织问题上的工联主义。
- 社会民主党 = 领导无产阶级全部解放斗争的革命家组织，不是经济斗争「执行组」。
- 名句：「给我们一个革命家组织，我们就能把俄国翻转过来！」任务是把手工业者提高为革命家，而非为降低辩护。

## 3. 「密谋」组织与「民主制」指责

- 建立向专制坚决开战的集中战斗组织 ≠ 民意主义；70 年代土地自由派已有出色组织；民意党错在理论与阶级联系，不在要战斗组织。
- 反对把政治斗争**缩小为**密谋，绝不等于否认坚强革命组织；在专制国，此种组织形式上可称 conspiration（秘密活动），秘密性是绝对条件。
- 「广泛民主原则」（选举制、全体表决、报告制）在公开政治舞台上可行；在宪兵选择盛行、革命家须对「所有人」十分之九隐瞒身份时，「广泛民主制」往往无意义且有害。
- 「原始民主」（人人轮流管理、事事全体表决）被英国工联史与考茨基批评证明为荒唐；需要代表机关与专职人员。

## 4. 结构图景（列宁计划）

- 党 = 少数领导人（主要是职业革命家）+ 广泛地方组织网；核心须有理论修养、才干、经验、考验，彼此配合。
- 外围：工会、自学小组、书刊小组、各居民阶层中的社会主义/民主主义小组——形式尽量不固定、秘密性尽量少；**不可**与革命家组织混同。
- 自发斗争若无坚强革命家组织领导，不能成为无产阶级真正的「阶级斗争」。

## 5. 与后书的接口

党员资格、集中制、反对小组习气——在[[One Step Forward — Party Rules Article 1]]与[[Democratic Centralism]]中变为党章与纪律之争。

---

> [!important] 一句话总结
> 在专制俄国，广泛而松散的「民主」工人党是空想；先有秘密、集中、专业的革命家组织，才能既做政治又保护群众组织。
