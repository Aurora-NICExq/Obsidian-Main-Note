# Surplus Value

> [!summary] 核心结论
> 剩余价值是雇佣工人在生产过程中创造、被资本占有、无需等价物的价值——其一般形式先于利润、利息、地租等特殊形式。量的核心是剩余劳动与必要劳动之比；资本通过延长工作日（绝对）与缩短必要劳动（相对）占有它。利润、平均利润、利息、地租是它在竞争与所有权结构中的转化形态。

> 关键词：m、m′＝m/v、绝对/相对、无酬劳动、转化形式

---

## 1. 一般规定

- 来源：劳动力的使用所创造的价值 > 劳动力自身价值。
- **必要劳动**：再生产劳动力价值；**剩余劳动**：创造 `m`。
- 不变资本 `c` 转移价值；可变资本 `v` 推动活劳动创造新价值 `v + m`。
- **剩余价值率** `m′ = m/v` 表示剥削程度；区别于利润率 `m/C`。

## 2. 绝对与相对

| | 绝对剩余价值 | 相对剩余价值 |
|--|--------------|--------------|
| 机制 | 延长工作日 | 提高生产力 → 降劳动力价值 → 缩必要劳动 |
| 前提 | 生产方式既定 | 变革技术与社会条件 |
| 典型杠杆 | 工作日斗争、加班 | 协作、分工、机器 |

- 超额剩余价值：个别生产力高于社会水平时的暂时多占有。
- 现实中二者结合；发展生产力是资本的内在趋势。

## 3. 与工资

- 工资使全部劳动表现为有酬 → `m` 被掩盖。
- 计件/计时是支付形式变化，不取消剩余劳动。

## 4. 转化形式链条

```text
剩余价值 m
  → 利润 p（对总资本）
    → 平均利润（部门间竞争）
      → 产业利润 / 商业利润
      → 利息 + 企业主收入
      → 地租（超额利润的土地所有权化）
```

- 第一卷在「一般形式」上把握；第三卷说明分割规律。见[[Capital — Vol3 Profit and Average Profit]]。

## 5. 常见误读

- 「利润来自流通加价」——混淆实现与产生。
- 「机器创造剩余价值」——机器属 `c`，提高生产力主要影响相对剩余价值与劳动力价值，价值源泉仍是活劳动。
- 把 `m` 直接等于日常「利润表利润」——忽略转化与分割。

---

> [!important] 一句话总结
> 剩余价值是资本无偿占有的剩余劳动的价值形式；一切「收入」范畴若离开它就会变得神秘。
