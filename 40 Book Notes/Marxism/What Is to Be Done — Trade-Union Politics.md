# What Is to Be Done — Trade-Union Politics

> [!summary] 核心结论
> 经济派把政治鼓动缩成「赋予经济斗争本身以政治性质」= 争取工厂立法改良的工联主义政治。社会民主主义政治要求全面政治揭露、把工人提高到对专制与资本主义整体的认识，并使争取改良服从争取自由与社会主义。

> 关键词：工联主义政治、政治揭露、先进战士、阶段论、改良与革命

---

## 1. 两套政治的区分

| | 工联主义政治 | 社会民主主义政治 |
|--|----------------|-------------------|
| 目标 | 出卖劳动力的较有利条件；国家减轻困苦的措施 | 消灭迫使穷人卖身给富人的制度；推翻专制 + 社会主义 |
| 鼓动中心 | 「同厂主和政府作经济斗争」 | 对专制制度的全面政治揭露 + 一切阶级关系中的政治教育 |
| 改良 | 当作主要或「新」任务 | 列入活动，但局部服从整体 |

- 工联不排斥「政治」，但那不是社会民主主义政治（英国工联早已为工厂法、工会合法化而斗争）。
- 「同政府作经济斗争」公式 = 工联主义政治的精炼标签。

## 2. 马尔丁诺夫路线为何是后退

- 「赋予经济斗争本身以政治性质」听来革命，实则把社会民主主义政治降低为争取经济改良。
- 阶段论残余：先在经济基础上搞政治，再「过渡」——即使《工人事业》口头修正，精神仍在「最普遍适用手段 = 经济斗争」一类说法中。
- 革命社会民主党：经济鼓动不仅要求政府措施，更要求政府不再是专制政府；并根据社会政治生活**一切**现象提出要求。

## 3. 政治揭露与「培养积极性」

- 具体号召只能在现场；政论家的任务是加深、扩大、加强政治揭露与鼓动——当场抓住并当众谴责，往往比抽象「号召」更有效。
- 迎合不开展工人心理的「能产生显著结果的具体要求」，常是重弹「每戈比工资」老调；工人革命家需要的是知识分子有责任提供、工人单靠工厂经验永远得不到的**政治知识**。
- 经济斗争获得政治性质往往自发发生（英国无需社会党人）；党的任务是把工联主义政治**变为**社会民主主义政治斗争。

## 4. 工人阶级作为争取民主制的先进战士

- 阶级政治意识只能从经济斗争外面、从工人—厂主关系范围外面灌输——须到居民一切阶级中去。
- 「到工人中去」不够；须在一切稍有觉悟的人民阶层中激起政治揭露热情。
- 只有组织真正全民揭露的党才能成先锋队；阶级性表现在：由社会民主党人组织、以社会民主主义精神说明问题、把全民民主斗争与无产阶级社会主义斗争结合成整体。
- 经济派以「阶级观点」反对争取同盟者、反对谈自由派不满 = 把先锋队降为后卫；工人自发抗议（如声援学生）有时超过党的自觉领导。

## 5. 经济主义与恐怖主义的邻近

- 两者都对政治鼓动与组织政治揭露不够积极：一个钻「激发性手段」，一个钻「具体要求」；都不能代替全面政治揭露工作。

---

> [!important] 一句话总结
> 政治不是经济斗争的自然「上层建筑」；全面政治揭露才是发展工人政治意识的不可替代工作。
