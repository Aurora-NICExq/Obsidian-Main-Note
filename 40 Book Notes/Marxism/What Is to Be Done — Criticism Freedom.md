# What Is to Be Done — Criticism Freedom

> [!summary] 核心结论
> 「批评自由」不是科学辩论的护身符，而是国际机会主义（伯恩施坦—米勒兰路线）要求在革命党内合法存在、把社会民主党改造成改良党的口号。俄国《工人事业》抄德国药方却不诊断俄国病，实质是无原则折中。

> 关键词：批评自由、伯恩施坦主义、米勒兰主义、教条主义指控、理论斗争

---

## 1. 「批评自由」的实质

- 国际社会民主党内已形成两派：革命派 vs 「新批评派」（否认唯物史观必然性、否认无产阶级专政、抹平自由主义与社会主义对立、把阶级斗争消解在「多数民主」中）。
- 列宁判断：看行为不看礼服——「批评自由」= 机会主义派在党内的自由 = 把党变为改良民主党的自由 = 把资产阶级思想灌入社会主义运动的自由。
- 「自由」口号的虚伪：工业自由、劳动自由曾掩护掠夺；真有科学新见，应要求用新观点**代替**旧观点，而非与旧观点「并列」的自由。

## 2. 国际样本

| 形态 | 要点 |
|------|------|
| 德国伯恩施坦派 | 理论修正；汉诺威、吕贝克等决议曾否决/警告，但调和派未彻底清党 |
| 法国米勒兰入阁 | 「实践的伯恩施坦主义」：以微小改良与阶级合作言词换取内阁席位，腐蚀社会主义意识 |
| 英费边派等 | 与法内阁派、德修正派、俄国批评派「一家弟兄」——第一次真正国际性的机会主义同盟 |

## 3. 俄国变体

- 《工人事业》把「批评自由」提为**政治统一条件**，却不点名俄国伯恩施坦派具体表现——「没有批评，也没有独立见解」，奴隶式模仿德国决议。
- 《信条》路线：工人做工联斗争，知识分子与自由派做「政治」——合法批评是后半部，工联工作是前半部。
- 德俄立场**相反**：德国革命派要保存既有纲领策略，批评派要改；俄国批评派/经济派要「保存现有」（承认「目前运动的正当性」），革命派要求改变流行策略——「在统一以前，并且为了统一，首先必须坚决而明确地划清界限」。

## 4. 理论斗争的意义（恩格斯线索）

- 社会民主运动三种斗争密不可分：政治、经济、**理论**。
- 名句：「没有革命的理论，就不会有革命的运动。」「只有以先进理论为指南的党，才能实现先进战士的作用。」
- 俄国更需要理论：党刚定面貌；清算未完成；借鉴别国经验不能照搬；民族任务空前重。
- 「反对僵化」的响亮词句往往掩饰理论冷淡：臭名远扬的批评自由 = 自由地抛弃完整理论，走向折中与无原则。

## 5. 方法提醒

- 划清界限先于虚假统一；口号须还原为派别行为。
- 「教条主义」指控常是掩护尾巴主义——检验标准是是否坚持革命纲领与独立阶级政治。

---

> [!important] 一句话总结
> 当「批评自由」成为统一条件而不说明批评什么，它就是机会主义的通行证。
