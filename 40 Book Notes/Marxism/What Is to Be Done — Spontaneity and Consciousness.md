# What Is to Be Done — Spontaneity and Consciousness

> [!summary] 核心结论
> 90 年代罢工相对「骚乱」已是进步，但仍是工联主义自发运动：工人感到与厂主对抗，尚未意识到与整个政治制度的不可调和。社会主义意识只能从外面灌输（von außen）；崇拜自发性 = 加强资产阶级意识形态对工人的支配。

> 关键词：自发性、自觉性、灌输、工联主义意识、意识形态对立、尾巴主义

---

## 1. 自发因素的层次

- 运动力量在于群众觉醒；弱点在于革命家缺乏自觉性与首创精神。
- 「自发因素」= 自觉性的萌芽：毁机器 → 有计划罢工（明确要求、择时、讨论别处经验）仍是工联斗争，不是社会民主主义斗争。
- 工人本来也不可能单靠自己有社会民主主义意识——各国历史证明：单靠自身只形成工联主义意识（结工会、同厂主斗、向政府争若干法律）。

## 2. 灌输论（核心命题）

- 社会主义学说产生于哲学、历史、经济理论，与无产阶级阶级斗争**并列**产生，不是从日常斗争中自发长出（考茨基论奥地利纲领的论证被列宁吸收）。
- 「从外面」：不仅从知识分子到工人，更指从经济斗争范围**外面**——从一切阶级与国家、政府关系中汲取政治知识（第三章展开）。
- 二者择一：资产阶级意识形态或社会主义意识形态；无第三种超阶级意识形态。对社会主义意识形态的任何轻视与脱离，意味着资产阶级意识形态的加强。
- 自发工人运动 = 工联主义运动 = 工人受资产阶级思想奴役的趋势；党的任务是**反对**这种自发性，把运动吸引到革命社会民主党羽翼下。

## 3. 对自发性的崇拜（书刊表现）

- 《工人思想报》：「为改善经济状况而斗争」「每个卢布增加一戈比比任何社会主义更实惠」——自觉性被自发性压倒。
- 「自我解放社」等：本能抓住「最初碰到的」斗争手段 = 工联手段 + 资产阶级意识形态；政治鼓动被规定为经济斗争的「上层建筑」。
- 《工人事业》：「群众性运动决定任务」被读成降低党为运动听差；「策略—计划与马克思主义矛盾」「策略是任务随发展而增长的过程」= 消极迁就自发性的纪念碑式表述。
- 「经济主义」名未必精确：他们不全盘否认政治，而崇拜从运动中自发生长的政治愿望，拒绝独立研究适合社会主义任务与俄国条件的社会民主主义政治。

## 4. 「工人自发倾向社会主义」如何读

- 在下列意义上正确：社会主义理论更深刻指明受苦原因，工人易于领会——**只要理论本身不屈服于自发性**。
- 同时：最流行的资产阶级意识形态又自发地、猖狂地迫使工人接受它。轻视自觉因素的谋士是运动幼年期的障碍。

## 5. 实践含义

- 缺点（领导人修养不足）不能粉饰成美德或归咎于「没有条件」。
- 「思想家」欣赏自己的落后、把物质环境说成绝对决定道路 = 屈从自发性。
- 先锋队若害怕自觉性超过自发性，就把「先锋」与「后卫」搞混了——见[[Vanguard Party]]。

---

> [!important] 一句话总结
> 不反对自发性的「工人政治」，默认走的是工联主义—资产阶级意识形态路线。
