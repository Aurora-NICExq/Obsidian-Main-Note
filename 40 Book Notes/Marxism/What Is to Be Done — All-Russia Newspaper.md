# What Is to Be Done — All-Russia Newspaper

> [!summary] 核心结论
> 全俄政治报计划不是文人习气：除利用全俄报纸外，没有别的方法培植强有力的政治组织。报纸是集体的宣传员、鼓动员，更是**集体的组织者**（脚手架）；围绕共同报纸的经常工作，同时准备起义又不丢掉日常鼓动。

> 关键词：全俄政治报、集体的组织者、脚手架、代办员网、正规围攻

---

## 1. 计划从何而来

- 回应《从何着手？》：如何在各地同时着手建立所需组织。
- 反对意见愈无根据、愈不从实质回答，列宁愈坚持该计划。
- 「策略—计划」：反对立刻号召冲击，要求组织对敌人要塞的**正规围攻**——集合、组织、动员常备军。

## 2. 报纸能不能成为集体的组织者？

- 纳杰日丁等：没有强有力地方组织，办得好的全俄报也无意义——列宁反驳：恰恰只有通过全俄报才能培植这种组织；「迷宫」论忽视政治生活是链条，须抓住可抓的一环。
- 脚手架比喻：搭在建筑物周围，显示轮廓、便于往来、分配工作、观察总成绩；房子建成可拆掉，但当前没有脚手架就盖不成所需房屋。
- 共同事业使小组不再以孤立手工业者身份开工，而以总攻击参加者身份修「小齿轮」；便于调动鼓动员/组织员，培养职业革命家与政治领袖。

## 3. 需要什么样式的组织

- 错误：专为爆发与街头、或专为「平凡日常」建党——交替无法预料，专制下可一夜剧变。
- 正确：把不论爆发或平静都能做的工作放在中心——阐明实际生活各方面、深入群众、**全俄范围统一的政治鼓动**；无经常出版的全俄报则不可想象。
- 破坏后的恢复：有共同工作时，两三个有干劲的人几周即可使新青年小组连上总中心。
- 起义准备：不是中央空派代办员「坐待」口号；在办报与发行中自然形成的代办员网做经常工作——巩固与工人及不满专制各阶层的联系，养成同时对全俄问题作出一致反应的习惯，这才是起义成功的条件。

## 4. 幻想与尾巴主义

- 「应当幻想」：跑到事变自然进程前面、用想象勾画刚成形作品的完成图——增强毅力；合法批评与不合法尾巴主义最缺这种幻想。
- 「革命前夜」借口放弃长期组织工作 = 冒险；真正不易错过革命的，是把全民政治鼓动放在纲领、策略、组织首位、编织以全俄报为中心的组织网的人。

## 5. 灵活与军事化比喻

- 组织须灵活：敌人集中一点时避免与优势敌人公开硬碰；利用敌人迟钝，在其难料的地点时间攻其不备。
- 「代办员」一词刺痛「民主」耳朵，但标明一切人为共同事业服务；需要的是军事化代办员组织意义上的协作。

> 共同报纸是建党的组织杠杆：先有全俄经常政治工作，才有稳定的战斗组织与起义准备。
