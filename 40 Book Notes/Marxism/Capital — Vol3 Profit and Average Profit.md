# Capital — Vol3 Profit and Average Profit

> [!summary] 核心结论
> 第三卷从「生产与流通的统一」走向资本在社会表面上的具体形式。剩余价值表现为超过成本价格的余额即**利润**，`m/v` 转化为 `m/C` 即**利润率**，从而掩盖起源。不同部门因[[Organic Composition of Capital|有机构成]]与周转不同，若按价值出售则利润率不等；竞争使资本转移，形成**平均利润**，商品价值转化为**生产价格**（成本价格＋平均利润）。价值规律并非被取消，而是通过生产价格间接贯彻。

> 关键词：成本价格 k、利润 p、利润率 p′、平均利润、生产价格

---

## 1. 第三卷的任务

- 第一卷：直接生产过程；第二卷：流通过程与再生产。
- 第三卷：资本运动整体所产生的具体形式——逐步接近竞争中当事人日常意识里的形态。

## 2. 成本价格与利润

- 商品价值 `W = c + v + m`。
- **成本价格** `k = c + v`：补偿资本家所耗费的资本；资本主义费用按资本耗费计量，实际费用按劳动耗费计量 → `k < W`（有 `m` 时）。
- `W = k + m` → 在表象上 `W = k + p`（利润）。
- **利润**：剩余价值作为全部预付资本的观念产物；`c` 与 `v` 在成本价格中失去职能区别，增殖好像来自总资本。
- 资本家可在低于价值但高于成本价格处出售仍获利润——为竞争与生产价格规律留出空间。

## 3. 利润率及其因素

- 利润率 `p′ = m / C`（`C` 为所使用的总资本），区别于 `m′ = m/v`。
- 影响利润率：剩余价值率、资本有机构成、周转时间、不变资本节约、原料价格等。
- 第一篇规律对利润率涨落的分析，在平均化之后仍具双重含义（部门内与一般层面）。

## 4. 平均利润与生产价格

问题：等量资本推动不等量活劳动 → 若按价值交换，利润率不等；但资本主义要求等量资本大致等量利润。

机制（逻辑）：

1. 不同部门有不同有机构成 / 周转 → 不同利润率；
2. 竞争引起资本流入利润率高的部门；
3. 供求变动使市场价格波动，直至形成**一般利润率**；
4. 商品按 **生产价格** = `k + 平均利润` 出售；
5. 有机构成高的部门：生产价格可高于价值；低的部门：可低于价值；总和上利润总量与剩余价值总量相联系（文本与恩格斯序言中的论争焦点）。

工资一般变动对生产价格的影响：取决于部门构成是否偏离平均等（专章讨论）。

## 5. 与「价值规律矛盾」论争（文本位置）

- 恩格斯在第三卷序言回顾洛贝尔图斯、施米特、法尔曼等尝试；强调要从一般剩余价值理解到利润/地租分配需经过中间环节。
- 学习要点：不要把第一卷的价值直接等同于第三卷的市场价格；中间范畴是成本价格、利润、平均利润、生产价格。

## 6. 过渡

- 一般利润率形成之后，可讨论其**趋向下降**（生产力发展 → 有机构成提高），以及利润再分割为利息与企业主收入、超额利润转化为地租——见[[Capital — Vol3 Interest Rent Crisis]]。

---

> [!important] 一句话总结
> 利润是剩余价值的神秘化形式；平均利润与生产价格是竞争在价值规律基础上配置社会资本的机制。
