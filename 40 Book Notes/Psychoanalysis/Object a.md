# Object a

> [!summary] 核心结论
> 对象 a：不是欲望要得到的经验对象，而是**欲望之因**——剩余、缺口、使欲望运转的原因性碎片。与小他者书写相关但功能上指向实在剩余。

> 关键词：欲望之因、剩余、幻象
