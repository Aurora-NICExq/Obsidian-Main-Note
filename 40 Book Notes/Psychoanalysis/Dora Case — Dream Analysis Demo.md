# Dora Case — Dream Analysis Demo

> [!summary] 核心结论
> 「杜拉」病例在套装中被定位为**弗洛伊德亲自示范梦的解析**：把《梦的解析》技术用于单个歇斯底里个案的梦，展示联想、象征与移情纠葛如何交织。

> 关键词：病例、歇斯底里、示范释梦、移情

---

## 1. 文本位置

出自《弗洛伊德心理学》套装中的分册；宜与梦工作笔记对照读，而非单独当小说。

## 2. 学习用法

1. 先遮住弗氏解释，自己对显梦元素联想
2. 再对照他的建构
3. 注意后日批评：性别政治、暗示、未完成分析等——当史学读

## 3. 技术收获

个案证明：释梦不是猜谜游戏，而是嵌入移情关系的工作。
