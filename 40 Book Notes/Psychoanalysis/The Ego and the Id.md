# The Ego and the Id

> [!summary] 核心结论
> 1923 结构模型：心灵不宜再简单等同「意识=自我 / 无意识=被压抑」。**自我部分无意识**（抵抗、无意识罪疚）；提出本我、自我、超我（自我理想）的机构图。

> 关键词：本我、自我、超我、无意识罪疚、结构模型

---

## 1. 问题从何而来

分析中发现：阻抗可源于自我；罪疚感可无意识——迫使修订「无意识=被压抑物」等式。

## 2. 三机构速写

| 机构 | 抓手 |
|------|------|
| 本我 | 激情储藏、原过程、力比多大仓库 |
| 自我 | 现实检验、控制运动、服务多方主子 |
| 超我 | 自我理想/良心、父母认同沉淀 |
