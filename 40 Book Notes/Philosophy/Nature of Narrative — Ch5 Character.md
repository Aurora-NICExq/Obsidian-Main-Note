# Nature of Narrative — Ch5 Character

> [!summary] 核心结论
> 人物塑造没有单一「正确」现实等级：阿喀琉斯的神话强度与伊莎贝尔·阿切尔的摹仿细度是**不同类型**，不是初级/高级。关键历史转折是内心呈现从**修辞性独白**转向**心理性/意识流**——与经验哲学、自传风尚、小说兴起同步。

> 关键词：神话性/摹仿性人物、修辞 vs 心理、内心独白、意识流、自传性姿态

---

## 1. 反詹姆斯中心论

亨利·詹姆斯「女人手搭桌沿的一瞥即事件」与「现实感优先」有效，但是**小说中心**的试金石。唐吉诃德「生动而不真实」、阿喀琉斯几乎只演「愤怒」一层——仍是高超塑造。智慧始于承认差异，终于取消伯仲迷信。

与意义章对齐：人物可偏例释、再现或美学；神话—传奇—摹仿构成光谱（详见 [[Plot and Character]]）。

## 2. 史诗人物：整全行动中的单一主题

- 《伊利亚特》：人物与情节共用主题「愤怒」——从激怒到平息（赫克托葬礼），而非英雄全传。
- 思想在古代常被当作「无声言语」→ 可用修辞技法呈现；直到近代才 interlock 心理学意义上的非言语思维。

## 3. 内心独白史（压缩）

| 阶段 | 特征 |
|------|------|
| 荷马 | 灵活、常导向行动；恐惧独白等程式存在但不僵 |
| 阿波罗尼奥斯 | 美狄亚：恋爱女性、危机、情欲 vs 忠孝、孤立、虑自杀——此后传奇独白模板 |
| 维吉尔 / 奥维德 | 修辞升级；奥维德可把思辨推到掩没人物的程度 |
| 希腊散文传奇 | 男女爱情独白成双；仍修辞 > 心理 |
| 乔叟 | 克瑞西达独白更心理化、社会化（「我是我自己的女人」）；特洛伊罗斯歌则极修辞 |
| 薄伽丘 | 把独白/思想分析从固定恋爱环节解放；自传性姿态加深心理 |
| 17–18 世纪 | 经验哲学 + 自传风尚；斯泰恩引入联想模式 → 人物可生成情节 |
| 19–20 世纪 | 叙事分析 vs 戏剧化独白；托尔斯泰安娜临终联想流；乔伊斯意识流；福楼拜少独白、用评述与「实体对应物」 |

口诀：**传奇独白偏修辞，现实主义独白偏心理**；时间与题材次于这一趋向性。

## 4. 小说人物的「自我投射」

笛福、理查逊、拉法耶特夫人、奥斯丁、巴尔扎克至乔伊斯/普鲁斯特——共性是对人物内心的特殊观照，常含艺术家心理的戏剧化投影（自传性**姿态**不必等于自传形式）。菲尔丁/萨克雷更多投射于叙述者角色；理查逊/斯泰恩把叙述者也人物化。

## 5. 现代难题（福楼拜）

若弃修辞强化、又坚持寻常人物的摹仿，如何避免平庸？《包法利夫人》的策略：节制独白、低调权威评述、用物件象征情感——预示后来「非人格化」争论（费伦章接布斯）。

> [!important] 一句话总结
> 先判断人物落在神话—传奇—摹仿光谱何处，再看其内心是演说术还是心理学。
