# History of Modern Philosophy — Spinoza Leibniz Wolff

> [!summary] 核心结论
> 斯宾诺莎把笛卡尔的“必然存在着的本质”洗炼为**盲目的必然存在者**：可能性被存在吞噬，自由（非存在之权能）消失——此概念是思维的监牢。莱布尼茨看似对立，实多为改头换面的斯宾诺莎主义（前定和谐、神义论中的有限性恶）；其贡献是层次分化萌芽与主观辩证法空间。沃尔夫把莱布尼茨理念学院化，形成康德所批判的独断形而上学。

> 关键词：必然存在者、实体、单子、前定和谐、乐观主义、本体论/宇宙论/自然神学

---

## 1. 斯宾诺莎：客观联系与监牢

- 笛卡尔学生：改造笛卡尔，提供真正**客观**联系；出发点是自在第一者——必然存在。
- 上帝 = 必然存在着的本质 / 绝对实体；剔除笛卡尔附加的道德—神学丰富性。
- 存在者本身：先于思维出现；不能不存在 → 排除潜能与自由。
- Causa sui 狭义化：本质直接过渡为存在；缺乏“也可以不存在”的权能 → 虚弱的盲目存在者。
- 谢林判词：此概念直至当时仍是一切事物的核心关键点、思维企图逃离却未成功的监牢。

与笛卡尔对比：身心偶因式同一性 → 斯宾诺莎实体性同一性（思维与广延作为属性）。

## 2. 莱布尼茨：对立假象

### 2.1 单子论并不真正胜过斯宾诺莎

- 清除广延、万物精神化：斯宾诺莎属性级广延本亦单纯不可分；形体可分常为不当抽象/模糊表象。
- 真正差别：斯宾诺莎保留属性间现实对立（本可推动发展）；莱布尼茨绝对一体论，差别仅是量的（完满度、意识有无），缺自在非精神性工具。
- 多单子最终仍归唯一原初实体（上帝）；“神性闪耀”生产派生单子——形象多于概念，近逻辑/内在流溢。

### 2.2 前定和谐

- 单子无窗；身心如两钟表由匠人预设同步。
- 谢林：斯宾诺莎“灵魂是身体的直接概念”的术语改写。

### 2.3 神义论 / 乐观主义

- 任务性写作（索菲公主等）：上帝在可能秩序中选最好者。
- 恶归于被造物必然有限性 / 褫夺 → 与斯宾诺莎“恶 = 较低肯定”同族；不能解释高能作恶。
- “道德必然性”调和自由与必然：淡化而非扬弃必然。
- 谢林猜想：单子论或近思想游戏；神义论更严肃——仍是斯宾诺莎主义的温和解释。

### 2.4 积极遗产

- 不满足于抽象谈事物，承认层次分化（沉睡/清醒单子）与走向自身的秩序萌芽。
- 反对客观僵化唯理论，重开未完成的主观辩证法；精神调和而非革命。
- 人物评价：德意志骄傲；时代限制下的切实调和者。

## 3. 沃尔夫与学院形而上学

- 沃尔夫以“无聊遐想”掌握莱布尼茨理念 → 另一种（主观）理性主义；神学理性主义多出此门；特权哲学地位。
- 莱布尼茨间接开启康德之前学院形而上学；康德对该形而上学 ≈ 笛卡尔对古代形而上学。

学院形而上学特征（谢林概括）：

1. 预设普遍概念为理智直接给定；外在应用于预设对象（灵魂、世界、上帝）。
2. “证明”= 把主谓放入固定命题联系，非对象内在自身证明。
3. 无贯穿全体的概念运动；分章重头开始。
4. 形式逻辑置于自身之外。
5. 门类：本体论（词典式先天概念）→ 理性心理学 / 宇宙论 → 理性神学（本体论、宇宙论、自然神学三证明皆不自足）。

终点缺陷：三证明仍未设定严格意义上作为造物主的上帝；否定属性与肯定属性并列，无过渡；上帝被放在形而上学尽头以安心——却非现实中的上帝秩序。

## 4. 过渡到康德

- 莱布尼茨—沃尔夫理性主义留下自由/必然、世界开端等虚假调和。

> 从斯宾诺莎的客观必然，经莱布尼茨的调和面具，到沃尔夫的学校形而上学：近代理性在“必然存在”监牢与独断证明机器之间摆动，等待康德的断裂。
