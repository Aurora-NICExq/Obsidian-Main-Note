# Plot and Character

> [!summary] 核心结论
> 情节是叙事的**动态连续**面；人物是意义与行动的主要载体。二者不互相废除：詹姆斯式「事件即人物状态」只覆盖摹仿小说的一段光谱。神话性人物与多瓣传奇情节自有其整全逻辑。

> 关键词：mythos、线性/多瓣情节、神话性—摹仿性人物、修辞/心理内心、进程

---

## 1. 情节（plot）

本书工作定义：动态、连续的元素；故事 ⊃ 情节（情节偏行动）。

历史形态速记：

- **原始史诗**：英雄事迹时间串联（文选式）。
- **《伊利亚特》型**：单一主题行动的紧密虚构聚焦。
- **传奇**：多瓣增生或精致对称惊奇。
- **流浪汉 / 早期小说**：单线经历模具。
- **历史叙事**：时间序列 + 必须有选择与运动才成「情节」。

详 [[Nature of Narrative — Ch6 Plot]]。

## 2. 人物（character）

光谱（勿排等级）：

| 倾向 | 特征 | 例 |
|------|------|-----|
| 神话/原型 | 主题高强度、细节少 | 阿喀琉斯—愤怒 |
| 传奇/修辞 | 理想或夸饰；独白如演说 | 希腊传奇恋人、巴洛克传奇 |
| 摹仿/心理 | 个体动机、社会嵌入 | 詹姆斯人物、布卢姆 |
| 例释/寓言 | 观念人形 | 斯宾塞财神、菲尔丁家庭教师 |
| 美学类型 | 情绪按钮，认知空 | 扁平反派/女主角功能位 |

内心史：古代「思想 = 无声言语」→ 修辞独白；近代心理学 + 自传风尚 → 意识流。详 [[Nature of Narrative — Ch5 Character]]。

## 3. 耦合法则

- 情节内在于主人公概念，惟行动实现之（《伊利亚特》愤怒主题同时约束人物与情节边界）。
- 意义章：人物随情节运动而改变例释/再现比重（斯奎尔从寓言哲学家跌入伪善场面）。
- 现实主义小说常把外在事迹骨架写淡，使「性格连续变化」抢戏——于是批评家宣布人物 > 情节；换传奇语料则结论反转。

## 4. 后经典补充（费伦）

- 用 **进程** 看情节：不稳定因素（故事）与紧张因素（话语）的时间部署。
- 人物三要素对读者三种关注：**摹仿 / 主题 / 合成**；不同文类前景不同要素，无普遍高下。
- 巴赫金激进版：人物与情节服务于方言—意识形态对话编排。

见 [[Nature of Narrative — Ch8 Theory 1966-2006]]。

## 5. 分析提问

1. 运动骨架是事迹串联、单主题闭合，还是心理连续？  
2. 人物主要在「求真」「求美」还是「求义」？  
3. 内心段落是讲给读者听的修辞，还是摹仿思维过程？  
4. 次要人物占多少「人物空间」——结构牺牲还是复调平等？

---

> [!important] 一句话总结
> 情节管运动，人物管载体与意义；先认光谱位置，再谈谁服从谁。
