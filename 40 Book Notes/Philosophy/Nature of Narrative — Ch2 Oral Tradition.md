# Nature of Narrative — Ch2 Oral Tradition

> [!summary] 核心结论
> 口头与书面是**形式**之别，不是文明/原始之别（帕里）。口头史诗靠**程式（formula）**与**程式模版**即兴生成；传递的是情节、母题、语汇「语法」，不是固定文本。书面叙事长期携带口头遗产——希腊史诗与北欧/冰岛传统是两大对照实验室。

> 关键词：程式、主题/论题（theme/topos）、母题、吟唱诗人、家族萨迦

---

## 1. 关键纠正

- 「文学」词源暗示书写；作者改用广义：一切语言艺术。
- 读写神圣化会低估文盲文化；苏格拉底《斐德若篇》反而忧虑书写损害记忆。
- Linear B 早于荷马书面化数百年却未服务文学；荷马创作远早于字母在希腊的广泛使用——帕里之后这一图景才可信。

## 2. 帕里—洛德模型

### 2.1 程式（formula）

帕里定义：在相同格律条件下反复使用的一组词，表达恒定核心理念（如「朱红似酒的大海」）。荷马语料高度程式化；书面诗人追求行行独特，口头诗人依赖可替换单元。

### 2.2 表演即创造

- 南斯拉夫吟唱者自认「一字不差」，实测两次表演词句不同、程式系统相同。
- 诗在表演前/后都不作为固定对象存在；传统是抽象工具，表演是独立创造。
- 「文本损伤」误解：口头传递可「完善」表演质量，但被传的是元素（情节、片段、母题、语汇），不是同一首诗实体。

### 2.3 程式模版与「语法」

洛德：具体程式次于**程式模版（formula system）**——可替换的抽象槽位。传统更像叠加在口语上的第二语法，约束如何构想世界（哈弗洛克读柏拉图责诗人：要从口头语法中解放思想）。

### 2.4 主题 / 论题

- 洛德「主题」：以程式化风格讲述故事的常用观念群（如迎客、贵族筵席）。
- 书中引入修辞学 **topos（论题）**：传统意象；指向外物 → **母题（motif）**；指向观念 → **主题（theme）**。口头中母题—主题耦合较稳；书面中诗人可拆解重组。

## 3. 作者身份

口头叙事很少绑定现代「作者」；荷马、基涅武甫等名字多是表演者/传统便利标签。伟大吟唱者把传统推到极限，而非站在传统外发明。

## 4. 冰岛对照：口头遗产的裂变加速器

约 1000–1300 年，书写进入后：

| 脉络 | 功能 |
|------|------|
| 《诗体埃达》残余 | 诗体口头传统 |
| 法律演讲人背诵法典 | 法律口头传统 |
| 宫廷诗、阿里、对话 | 历史口头传统 |
| 家族萨迦 | 书面却高度程式化；神话缩、摹仿/历史增 → 近「现实主义虚构」 |
| 《天下》《斯特龙戈萨迦》 | 谱系史、事件史；法律理性替哲学推论清洗神话 |

要点：冰岛在孤立中压缩完成了欧洲更漫长的「史诗 → 历史/传奇分化 + 新综合」；家族萨迦证明文盲文化也能孕育世俗史与散文叙事——品性卓越不能反证「必为书面个体创作」。
