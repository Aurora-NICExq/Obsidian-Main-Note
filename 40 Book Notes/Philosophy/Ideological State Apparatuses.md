# Ideological State Apparatuses

> [!summary] 核心结论
> 意识形态国家机器（ISA / 法文 AIE）是阿尔都塞对马克思主义国家理论的核心补充：与镇压性国家机器（RSA）并立，**首要通过意识形态**（辅以镇压）发挥功能，其系统功能是保障[[Reproduction of Relations of Production|生产关系的再生产]]。公私法律身份不决定是否为「国家」机器；当代资本主义中**学校**（配合家庭）是占统治地位的 ISA。

> 关键词：AIE/ISA、RSA、学校、占统治地位的意识形态、物质机器

---

## 1. 定义与对立

| | RSA（镇压性国家机器） | ISA（意识形态国家机器） |
|--|----------------------|-------------------------|
| 数量表述 | 常作统一的一套 | 复数、相对自主的多样机器 |
| 首要功能 | 暴力 / 镇压 | 意识形态 |
| 次要功能 | 也做意识形态灌输 | 也用开除、规训、审查等镇压 |
| 典型机构 | 政府、行政、军队、警察、法院、监狱 | 学校、家庭、教会、政党/议会、工会、传媒、文化等 |

理论干预点：不能把国家化约为 RSA；也不能把 ISA 化约为「观念传播」。

## 2. 临时清单（书中）

1. 学校机器  
2. 家庭机器  
3. 宗教机器  
4. 政治机器  
5. 工会机器  
6. 传播机器  
7. 出版—发行机器  
8. 文化机器  

清单可修订；每种 ISA = 机构/组织系统 + 在其中实现的意识形态。

## 3. 运转逻辑（压缩）

1. 掌权阶级实施国家政权 → 调度 RSA + 诸 ISA  
2. 占统治地位的意识形态贯通多样 ISA，赋予其统一  
3. ISA 把本领培养与臣服训练结合起来，按劳动的社会—技术分工「投放」主体  
4. 主体经由[[Interpellation|唤问]]承认自己的名字与岗位，从而「自动运转」  
5. 结果：资本—雇佣关系明天仍在

## 4. 学校命题

- 前现代长时段：教会常为主导 ISA  
- 资本主义：学校在功能上取代教会；沉默、世俗、「中立」的自我表述正是其意识形态力量  
- 政治 ISA 可换装（议会/威权），学校—家庭的日常再生产更稳定、更深层

## 5. 阶级斗争内置于 ISA

- ISA 是统治阶级工具，但也是阶级斗争的舞台（教师造反、工会对立意识形态、五月风暴中的学校等）。
- 革命：打碎 RSA 之外必须改造/更换 ISA；否则旧意识形态继续再生产旧关系。
- 政治/工会 ISA 中的特殊风险：议会迷与经济主义（见 [[Althusser — State and State Apparatuses]]）。

## 6. 判别口诀

问四个问题：

1. 它首要靠说服/仪式/教育，还是靠暴力？  
2. 它是否实现占统治地位（或对抗）的意识形态？  
3. 它是否有助于把当事人安置进阶级岗位？  
4. 公私法律标签是否在转移视线？

---

> [!important] 一句话总结
> ISA 是用意识形态使人自动就位的国家机器；学校是资本主义日常再生产的主力装置。
