# Althusser — State and State Apparatuses

> [!summary] 核心结论
> 第 6–8 章完成国家理论的关键拓展：经典马克思主义把国家理解为阶级镇压机器是正确但**描述性**的；必须区分**国家政权**与**国家机器**，并在镇压性国家机器（RSA）之外并列复数的[[Ideological State Apparatuses|意识形态国家机器（AIE/ISA）]]。RSA 首要靠暴力，ISA 首要靠意识形态（辅以镇压）。第 7–8 章以法国资本主义形态中**政治的与工会的 ISA**为个案：无产阶级组织可进入资产阶级 ISA 内部，但改良主义（议会迷/经济主义）是结构性风险；群众的经济—政治阶级斗争仍是突破合法形式的根基。

> 关键词：国家政权、国家机器、RSA、ISA/AIE、公私之分、政治ISA、工会ISA

## 1. 第 6 章：国家和国家机器

### 1.1 从描述性理论推进

马克思主义传统（宣言、雾月十八日等）明确：国家是统治阶级的镇压机器。这能解释大屠杀到审查等大量事实，但仍是「描述性理论」——需被理论化超越。

### 1.2 必须引入的区分

| 概念 | 含义 |
|------|------|
| 国家政权 | 哪个阶级（联盟）掌握国家 |
| 镇压性国家机器 RSA | 政府、行政、军队、警察、法院、监狱等；最终可使用肉体暴力 |
| 意识形态国家机器 ISA | 与 RSA 并立、不可混同的「另一现实」；首要通过意识形态发挥功能 |

没有革命的国家理论，就不会有革命的运动——补充 ISA，是给阶级斗争实践中已承认的复杂性赋予理论形式。

### 1.3 ISA 临时清单（正文）

1. 学校　2. 家庭　3. 宗教　4. 政治　5. 工会　6. 传播　7. 出版—发行　8. 文化  
（作者自承不完整；7/8 或可合并；详见概念笔记。）

### 1.4 功能区分与「公私」伪反驳

- **RSA**：首要镇压，次要意识形态（军队内部灌输、对外「说服」等）。
- **ISA**：首要意识形态，次要镇压（开除、规训、审查等）。
- 公私法律身份**不能**否定 ISA 的国家性：关键是是否实现统治阶级意识形态、服务生产关系再生产。教会、私立传媒、政党制度等皆可如此。

### 1.5 每种 ISA 的「统一」

每种 ISA 由机构/组织系统构成；统一它们的是在其中实现的意识形态（物质实践中的实现）。意识形态「扎根」于不能完全化约为意识形态的现实（学校的本领、政治/工会中的阶级斗争、家庭消费单位等）——宗教看起来最「纯意识形态」，作者存疑待后文。

### 1.6 革命含义（预告）

夺取政权、打碎 RSA 不够；还必须摧毁并更换 ISA。若新政权下机器仍靠旧资产阶级意识形态运转，再生产的是旧关系的幽灵（对苏联「个人崇拜」、计划化困境等提出尖锐追问）。

## 2. 第 7 章：法国形态下的简要说明

- 政治 ISA 与工会 ISA 中，可以同时实现**资产阶级意识形态**与（通过阶级斗争）保留的**无产阶级意识形态**——二者原则对抗。
- 无产阶级组织出现在资产阶级 ISA 中，是阶级斗争发展的后果，不是逻辑意外。
- 结构性偏向：对政党 → 「议会迷」；对工会 → 「经济主义」——改良主义的两种形式。
- 法国史速写（大革命、街垒、公社等）说明：合法形式中的斗争是另一场更广阔阶级斗争的「接续（relais）」。

## 3. 第 8 章：政治的和工会的意识形态国家机器

### 3.1 核心论题

- 民主、选举、议会自由等是政治 ISA 的仪式与形式；其阶级内容由谁掌握政权、机器为谁服务决定——「各有各的民主」。
- 工会的经济斗争必要但不够；没有与政治阶级斗争的融合，无法触及国家。历史「验证」：仅靠工会经济主义不能导向社会主义变革。
- 「创造历史的是群众」：议员奇迹多数 ≠ 革命；必须把政治斗争植根于经济斗争的物质基础。

### 3.2 意识形态副产品

在法国政治 ISA 中运转的主题丛：民族主义、道德主义、经济主义、人文主义/人道主义等——与占统治地位的意识形态统一体相联（为第 9 章学校章与第 12 章作支撑）。

### 3.3 策略警戒

- 把工会误认为可替代政党去「占据」政治功能 = 危险错位。
- 改良主义不仅腐蚀「知识分子」，也影响工人运动内部某些阶层。
