# GPIO Principles

> [!summary] 核心结论
> GPIO 挂载在 **APB2** 总线上，每个端口含 16 个引脚，内核通过读写寄存器实现输出电平与读取电平。引脚电平 0V~3.3V，引脚定义中带 **FT** 的可容忍 5V 输入。通过端口配置寄存器可配置成 **8 种模式**（浮空 / 上拉 / 下拉 / 模拟 输入，推挽 / 开漏 输出，复用推挽 / 复用开漏 输出）。输出级由 P-MOS + N-MOS 构成：**推挽**高低电平都由芯片主动驱动；**开漏**只能主动拉低，高电平为高阻态、需外部上拉，驱动能力更灵活，但要配合耐 5V 的 FT 引脚。

---

## 1. 简介

GPIO（General Purpose Input Output）通用输入输出口（即 IO 口），可配置为 8 种输入输出模式。

### 1.1 电平与电压范围

- 引脚电平：0V~3.3V，部分引脚可容忍 5V
	1. 数据 1 是高电平，0 是低电平
	2. 输入可达 5V，最大输出 3.3V（引脚定义中带 FT 可以容忍） ^460c10

### 1.2 典型用途

- **输出模式**下可控制端口输出高低电平，用以驱动 LED、控制蜂鸣器 / 继电器 / 三极管与 MOS 管、模拟通信协议输出时序（bit-bang）等
- **输入模式**下可读取端口的高低电平或电压，用于读取按键输入、外接模块电平信号输入、ADC 电压采集、模拟通信协议接收数据等

## 2. 基本结构

![[d2-gpio-principles-01.svg]]

- GPIO 挂载在 APB2 外设总线上，每一个包含 16 个引脚
- 内核通过 APB2 总线对寄存器读写，实现输出电平和读取电平的功能
- 寄存器每一位对应一个引脚，寄存器是 32 位，低 16 位对应端口

## 3. GPIO 位结构

![[image-20260122185547132.png]]

### 3.1 输入通路

#### 3.1.1 保护二极管

- 输入电压大于 3.3V，上方二极管导通，电流流入 VDD（电流由电源吸收）
- 输入电压小于 0V（相对于 VSS），下方导通，电流从 VSS 流出（电流由 GND 吸收）

#### 3.1.2 上拉与下拉

- 上拉电阻接高电平
- 下拉电阻接低电平

#### 3.1.3 TTL 肖特基触发器

> [!note]
> ST 中文手册图 13 中标注为「TTL肖特基触发器」，其实质是**施密特触发器**（Schmitt Trigger）。

- 输入电压大于阈值，输出升为高电平
- 输入电压低于阈值，输出降为低电平

用于消抖，[[Hardware Circuits#3.1 二值化|电压比较器（LM393）]]

#### 3.1.4 模拟输入与数字输入

- 浮空、上拉、下拉读取高低电平，称为**数字输入**
- **模拟输入**读取电压具体数值，引脚直接接入内部 ADC；ADC 用于模拟信号转数字信号

### 3.2 输出驱动器：MOS 管

输出级由 P-MOS 与 N-MOS 组成，两者的工作方式决定了推挽与开漏两种输出类型。

#### 3.2.1 推挽输出（Push-Pull）

高低电平都由芯片主动驱动，最常用。推挽输出下 P-MOS、N-MOS 协同工作：

- IO 口输出高电平，P 激活，N 关闭。VDD 与 IO 引脚导通。
- IO 口输出低电平，P 关闭，N 激活。VSS 与 IO 引脚导通。

#### 3.2.2 开漏输出（Open-Drain）

只能主动拉低，拉高靠外部上拉，适合“线与”总线（如 [[I2C]] 思路）。开漏输出用于 VDD 电压大小不够的情况：

- N-MOS 工作，P-MOS 断开
- IO 口输出高电平，N 断开，电路断路
- IO 口输出低电平，GND 外接 5V，电压“漏”进来

1. **开漏输出依靠外部电源提供驱动能力，因此更加灵活**
2. 开漏输出需要使用能够容忍 5V 的 IO 口 [[GPIO Principles#^460c10|FT能够容忍5V]]

### 3.3 寄存器

- 输出数据寄存器同时控制 16 个端口，只能进行整体读写
- 位设置寄存器可用于单独修改一位数据，而不影响其它位

## 4. GPIO 八种模式

^c3df2c

- 配置 GPIO 的端口配置寄存器，可以将端口配置成 8 种模式

| **模式名称**     | **性质** | **特征**                                           |
| ---------------- | -------- | -------------------------------------------------- |
| **浮空输入**     | 数字输入 | 可读取引脚电平，若引脚悬空，则电平不确定           |
| **上拉输入**     | 数字输入 | 可读取引脚电平，内部连接上拉电阻，悬空时默认高电平 |
| **下拉输入**     | 数字输入 | 可读取引脚电平，内部连接下拉电阻，悬空时默认低电平 |
| **模拟输入**     | 模拟输入 | GPIO无效，引脚直接接入内部ADC                      |
| **开漏输出**     | 数字输出 | 可输出引脚电平，高电平为高阻态，低电平接VSS        |
| **推挽输出**     | 数字输出 | 可输出引脚电平，高电平接VDD，低电平接VSS           |
| **复用开漏输出** | 数字输出 | 由片上外设控制，高电平为高阻态，低电平接VSS        |
| **复用推挽输出** | 数字输出 | 由片上外设控制，高电平接VDD，低电平接VSS           |

1. 一个端口只能够有一个输出，但是可以有多个输入。
2. 除了模拟输入，其它七种模式输入均有效
