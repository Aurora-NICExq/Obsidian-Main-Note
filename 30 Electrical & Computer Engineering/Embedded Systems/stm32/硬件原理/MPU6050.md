# MPU6050

> [!summary] 核心结论
> MPU6050 是六轴 IMU（3 轴加速度计 + 3 轴陀螺仪），通过 [[I2C]] 读写寄存器操作，从机地址 `0xD0`。加速度数据是 **16 位有符号数**，需把高低字节拼接。单独用陀螺仪积分会**漂移**，单独用加速度计算倾角会**噪声大**，因此用**互补滤波**融合：对陀螺仪取高通、对加速度计取低通，权重 $\alpha$ 通常取 0.95~0.98。

---

## 1. 简介

MPU6050 是一款**六轴姿态传感器**，也叫 **IMU（惯性测量单元）**。它内部集成了：

- **3轴加速度计**
- **3轴陀螺仪**

所以它可以同时测量物体的**加速度变化**和**角速度变化**，常用于检测设备的**倾斜、转动、姿态变化和运动状态**。

## 2. 寄存器读写

### 2.1 写寄存器

① 同时发送寄存器的地址和值

```c
// 向寄存器0x1b写入值0x18
i2c_send_bytes(0xd0, {0x1b, 0x18})  //0xd0是MPU6050的地址
```

### 2.2 读寄存器

① 发送寄存器地址
② 读取寄存器的值

```c
// 例如：读取寄存器0x3b的值
i2c_send_bytes(0xd0, 0x3b);

regVal = i2c_receive_bytes(0xd0);
```

### 2.3 MPU6050 初始化

```c
// #2. 设置MPU6050的参数
reg_write(0x6b, 0x80);  // 复位 ，类比RxNE
Delay(100);

reg_write(0x6b, 0x00);  // 关闭睡眠模式

reg_write(0x1b, 0x18);  // 陀螺仪量程，+-2000度/s
reg_write(0x1c, 0x00);  // 加速度计量程，+-2g
```

### 2.4 读取加速度计

```c
uint8_t accel_xout_h = reg_read(0xd0,0x3b);

uint8_t accel_xout_l = reg_read(0xd0,0x3c);

int16_t ax_raw = accel_xout_l + (accel_xout_h << 8);
```

- `0x3B`：读取加速度 X 轴高字节 `ACCEL_XOUT_H`
- `0x3C`：读取加速度 X 轴低字节 `ACCEL_XOUT_L`
- MPU6050 的加速度数据是 **16位有符号数**
- 所以需要把高 8 位和低 8 位拼起来，得到最终原始值 `ax_raw`

## 4. 互补滤波

![[tikz-mpu6050-01.svg]]

**两种方式单独计算都会造成较大误差**

### 4.1 计算方法

设当前要求某个轴的角度（比如 Pitch）：

#### 4.1.1 先用陀螺仪积分

$$\theta_{gyro} = \theta_{last} + \omega \cdot dt$$

其中：

- $\theta_{last}$：上一时刻角度
- $\omega$：陀螺仪测得的角速度
- $dt$：采样周期

#### 4.1.2 再用加速度计算倾角

例如：

$$\theta_{acc} = \arctan\left(\frac{A_x}{A_z}\right)$$

或根据不同坐标系写成别的形式。

#### 4.1.3 最后做加权融合

$$\theta = \alpha \cdot \theta_{gyro} + (1 - \alpha) \cdot \theta_{acc}$$

其中：

- $\alpha$ 一般取 **0.98、0.95** 这类接近 1 的值
- 表示：**大部分相信陀螺仪，小部分用加速度计纠偏**

### 4.2 作用

- 对陀螺仪部分做了**高通特性**
  保留快速变化，抑制低频漂移
- 对加速度计部分做了**低通特性**
  保留慢变化的稳定趋势，抑制高频抖动

两者频域上是“互补”的，所以叫互补滤波。
