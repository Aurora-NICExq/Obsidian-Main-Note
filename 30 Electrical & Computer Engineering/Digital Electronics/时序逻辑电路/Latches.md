# Latches

> [!note]
>
> 时序逻辑电路的输出不仅取决于当前输入，还取决于过去的输出或状态
>
> 异步:状态变化不受统一时钟控制。
>
> 同步：如控制锁存器，状态只在时钟或使能信号允许时改变



## RS锁存器

![[tikz-latches-01.svg]]

### 真值表

Case – 1:

S = 0, R = 1 ⇒ Q = 0, Q̅ = 1

S = 0, R = 0 ⇒ Q = 0, Q̅ = 1

Memory state is achieved with S = 0, R = 0

Case – 2:

S = 1, R = 0 ⇒ Q = 1, Q̅ = 0

S = 0, R = 0 ⇒ Q = 1, Q̅ = 0

Memory state is achieved with S = 0, R = 0

Case – 3:

S = 1, R = 1 ⇒ Q = 0, Q̅ = 0 **(此时不能保持在稳定状态)**

S = 0, R = 0 ，门延迟现象会导致实际电路中稳定，但是会失去存储功能。

## 时钟信号与使能信号

使能信号一般不是周期性节拍，而是一个控制开关，时钟信号一般是周期性方波。

时钟信号负责规定“什么时候采样/更新状态”；使能信号负责规定“这次要不要更新”。
