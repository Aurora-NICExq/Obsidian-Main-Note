# Flip-Flops

> [!note]
>
> 触发器与锁存器电路相同，引入时钟信号来实现同步，就将其称作触发器。

## 时钟与输出变化

### 电平触发

**电平触发**是指：当时钟信号处于某一个有效电平时，触发器或锁存器会对输入信号作出响应。

有效电平可以是：

- **高电平有效**
- **低电平有效**

### 边沿触发

**边沿触发**是指：触发器只在时钟信号发生跳变的瞬间响应输入信号。

边沿触发又分为两种：

- **上升沿触发**
- **下降沿触发**
> 比电平触发更适合用于同步时序电路，比如寄存器、计数器、状态机等。

### 激励表
作用：已经知道触发器的**当前状态**和希望得到的**下一状态**时，反过来查出触发器输入端应该加什么信号。

## 常见触发器

### D触发器
![[tikz-flip-flops-03.svg]]

核心功能：在时钟有效边沿到来时，把 D 的值保存到 Q 中
特征方程：
$$
Q_{n+1}=D
$$

### JK触发器
![[tikz-flip-flops-04.svg]]

| CLK     | J    | K    | Q₊   |
| ------- | ---- | ---- | ---- |
| 0, 1, ↓ | x    | x    | Q    |
| ↑       | 0    | 0    | Q    |
| ↑       | 0    | 1    | 0    |
| ↑       | 1    | 0    | 1    |
| ↑       | 1    | 1    | Q̅    |

**JK触发器实现了翻转功能**

### 特征方程

$$
Q_{n+1} = \overline{Q_n} \cdot J + Q_n \cdot \overline{K}
$$



### 预设和清除

触发器除了正常的时钟输入、数据输入之外，常常还有两个**异步控制输入**：

```
预设 Preset / Set
清除 Clear / Reset
```

它们的作用是：**不等时钟信号，直接强制改变 Q 的状态。**

1. **预设**的作用是：强制让触发器输出为 1。

2. **清除**的作用是：强制让触发器输出为 0。
