# Markdown Syntax

表示标题：井号#，每多一个字体变小一号
加粗文本：两个星号+内容+两个星号*
斜体：单个星号。 
项目符号列表：-加上空格,按tab键嵌套,两次回车回到上一级
编号列表：数字1. 空格
反向链接（到另一个笔记）：[[]]  ，[](http)链接到其它地址
高亮文本： 两个等号=
删除线：两个波浪线～
复选框：-加空格+[]括号中间加空格，后面再加一个空格
标签：连续三个-

超链接添加[google]（链接地址"标题提示"）
引用：使用>进行引用，支持嵌套
顶部三个破折号：--- 添加笔记属性

|**关键词 (Type)**|**颜色**|**默认图标**|**适用场景**|
|---|---|---|---|
|`note`|🔵 蓝色|✏️ 铅笔|通用笔记|
|`tip` / `hint`|🟢 青/绿|🔥 火焰/灯泡|技巧、窍门 (你图中用的就是这个)|
|`success` / `check`|🟢 绿色|✅ 勾号|完成、正确答案|
|`warning` / `caution`|🟠 橙色|⚠️ 三角感叹号|注意事项、警告|
|`danger` / `error`|🔴 红色|⚡ 闪电/叉号|错误、危险操作|
|`example`|🟣 紫色|☰ 列表|举例说明|
|`quote`|🔘 灰色|❞ 双引号|引用名言|
|`question`|🟡 黄色|❓ 问号|问题、思考|
